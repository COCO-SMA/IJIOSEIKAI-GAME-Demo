## 一、游戏概述

### 1.1 一句话描述

一款以鲲城为舞台的奇幻现代回合制 JRPG，玩家扮演在鲲城出生的角色，经历完整一生，通过多代继承构建家族传奇，在 Roguelike 式的不可预测中探索这座城市"不太对劲"的一面。

### 1.2 核心标签

- **类型**: 回合制 JRPG + Roguelike + 养成
- **舞台**: 鲲城市（11个区级行政单位）
- **世界观**: 奇幻现代（非魔幻——奇幻的核心是不可预测，不是元素克制）
- **美术风格**: 像素风
- **目标平台**: 桌面应用（Electron 打包）
- **技术栈**: HTML5 Canvas + JavaScript + Electron
- **单局时长**: 1.5-2 小时/一生
- **战斗深度**: 中等（1-3人小队，技能+站位，无元素克制）

### 1.3 核心体验目标

让玩家**沉浸**在一个既熟悉又陌生的鲲城——日常生活的质感里藏着不对劲的裂缝。笑着玩，但也认真投入。每一代角色都有独特的故事，每一次重玩都有新的惊喜。

## 二、设计哲学

### 2.1 奇幻 ≠ 魔幻

| 维度 | 魔幻（不做）        | 奇幻（要做）          |
| -- | ------------- | --------------- |
| 体系 | 有规律、有元素克制     | 不可预测、不服从规律      |
| 来源 | 外部引进（龙、精灵、魔法） | 从日常裂缝里长出来       |
| 鲲城 | 贴纸（换到北京也成立）   | 骨架（离开鲲城就不是这个游戏） |
| 克制 | 火克冰           | 没有固定克制——上下文决定效果 |
| 调性 | 严肃世界观         | 正经设定 + 荒诞日常，笑着玩 |

### 2.2 核心原则

1. **奇幻不从外面引进，从日常的裂缝里长出来** — 不是"鲲城来了条龙"，而是"鲲城一直有点不对劲，只是大部分人没注意到"
2. **异常是搞笑的，不是恐怖的** — 从空口袋掏出东西但永远不是你想要的；右腿带你绕路但你发现了隐秘面馆
3. **出身是具体的，不是抽象的** — "政治家族的孩子"比"现实扭曲者"直观一百倍
4. **组件是可看见的，不是藏起来的** — 6个身体部位，6个装备栏，一眼就看懂
5. **故事钩子是生活化的** — "你爸会知道的"、"突然破产"、"收租日见了不太像人的租客"
6. **Roguelike 的不可预测性来自"随机法则"，不是"随机地图"** — 同一个道具换个区可能效果完全不同

### 2.3 幽默标准

游戏的灵魂是**有趣**。不是温情，不是感动，是让玩家笑出声。具体标准：

1. **美式幽默 + 无厘头混搭** — 参考《南方公园》的社会讽刺胆量、《脱口秀大会》的日常荒诞感、《银魂》的打破第四面墙。正经设定配不正经表述，反差就是笑点
2. **一句话原则** — 每个异常描述、道具说明、NPC台词，至少有一句让人想截图发讯圈的话。如果一段文案读完了没有笑点，重写
3. **不解释笑点** — 好笑的东西不需要解释。如果你需要加一句"（这是在说XXX）"，那这个笑话就死了
4. **荒诞但自洽** — 设定可以离谱，但在离谱的设定内部必须讲逻辑。"鲲通卡有自己的品味"是离谱的，但它"在钟岭偶尔送你到没选的站"是自洽的
5. **避免煽情** — 温情可以有，但不能主动煽。感动应该是玩家自己感受到的，不是文案逼出来的。如果一段文字读起来像在催泪，删掉重写
6. **角色有态度** — 系统提示、升级通知、物品描述都要有"人味"，不是机器播报。系统的语气是"一个嘴贱但靠谱的朋友在给你解说"

### 2.4 调性参考

- 《Rogue Legacy》的继承机制
- 《Persona》系列的日常+冒险交替
- 《极乐迪斯科》的叙事选择感
- 《银魂》的"正经设定配不正经执行"
- 《南方公园》的"什么都能拿来开玩笑"
- 整体调性：**笑着玩，偶尔被一句话击中，然后继续笑着玩**

## 三、世界观

### 3.1 舞台：鲲城

鲲城，一座超一线城市。表面上是科技、金融、效率的现代都市。但如果你在这里生活得够久，你会注意到一些"不对劲"——

- 末班地铁后偶尔多出一班不在时刻表上的车
- 某栋写字楼的电梯按7楼会到一间不该存在的办公室
- 东墟地摊上偶尔卖一些来路不明的东西
- 港口集装箱里有时候装着不该存在的东西

大部分人不会注意到，或者注意到了也选择忽略。但有些人——感知特别敏锐的，或者机缘特别好的——会撞上这些裂缝。

### 3.2 奇幻层 vs 现实层

游戏不刻意区分"现实层"和"奇幻层"。异常事件混在日常中自然发生，玩家不需要"进入副本"才能遇到怪事——它就在通勤路上、在夜市摊位旁、在收租的时候。

### 3.3 鲲城的"不对劲"

每个区有不同性质的"不对劲"，这不是数值加成，而是改变"现实运转的方式"：

| 区域 | 异常类型 | 日常表现                  |
| -- | ---- | --------------------- |
| 金涌 | 权力异常 | 某些规则在这里真的会被执行——包括不成文的 |
| 云墩 | 信息异常 | 数据流里偶尔混着不该存在的信息       |
| 旧墟 | 旧物异常 | 老东西会记住事情，有时会告诉你       |
| 铁围 | 制造异常 | 造出来的东西偶尔不是你设计的那个      |
| 岔岗 | 路径异常 | 路会自己变，但变化的路总有理由       |
| 盐澳 | 来路异常 | 港口来的东西有时不是从任何地方来的     |
| 钟岭 | 时间异常 | 通勤路上时间偶尔不太对劲          |
| 野坪 | 山林异常 | 山里有些东西很老，比城市老得多       |
| 禾塘 | 生长异常 | 种出来的东西偶尔不是你种的         |
| 潮湾 | 潮汐异常 | 海边的东西有自己的脾气           |
| 边埔 | 边境异常 | 新旧交替的地方，什么都有可能        |

> **注意**: 这些异常类型是设计方向，不是硬规则。具体表现为日常化的、搞笑的、戏剧性的事件，不是恐怖或晦涩的。

## 四、核心玩法循环

### 4.1 一生的结构

> 详细系统设计见第三十四章（生命周期系统）。

```
出生（选区域 + 出身 + 投胎签）
  ↓
婴儿期 0-5（自动播放 + 关键选择 + 突发事件；第二代起跳过）
  ↓
童年期 6-12（4动作/年，二级菜单 + 无厘头选项）
  ↓
少年期 13-18（10动作/年，首次自由行动，第一个异常事件教学）
  ↓
青年期 19-35（14动作/年，组建小队，核心冒险期）
  ↓
壮年期 36-65（14动作/年，能力巅峰，高难度挑战，培养后代）
  ↓
中年期 66-80（14动作/年，传授经验，经营家族）
  ↓
老年期 81+（14动作/年，属性衰退，传承准备，最终事件）
  ↓
寿终 → 继承 → 下一代（或血脉断绝 → 结局"最后的鲲生"）
```

### 4.2 单局节奏（约 2 小时/一生）

> 一生约 1000 个可控动作，前期快后期慢。详见第三十章（探索地图系统）和第三十四章（生命周期系统）。

| 阶段 | 时长     | 核心活动                |
| -- | ------ | ------------------- |
| 童年 | ~5min | 二级菜单选择，无厘头选项，数值定型 |
| 少年 | ~15min | 自由探索首次开放，第一个异常事件教学  |
| 青年 | ~40min | 核心冒险期，组队、探索、战斗、任务   |
| 壮年 | ~30min | 高潮期，高难度挑战，开始培养后代    |
| 中年 | ~15min | 传授经验，家族经营，选择传承内容    |
| 老年 | ~15min | 属性衰退，最终事件，收束叙事，传承准备 |

### 4.3 多代循环

```
第1代 → 城市不认识你，异常事件像在赶客 → 寿终 → 传承
                                                          ↓
第2代 → 城市有点面熟了，异常事件不再那么吓人 → 寿终 → 传承
                                                                  ↓
第3代 → NPC开始认识你了，"你是老X家的？" → 寿终 → 传承
                                                            ↓
                                                    ... (5-8代)
                                                            ↓
                                              11区都扎根 → 地头认证结局
```

## 五、出身系统

### 5.1 通用出身（全区域可选）

| 出身   | 初始优势       | 初始劣势  | 特色                         |
| ---- | ---------- | ----- | -------------------------- |
| 普通人  | 机缘略高       | 各项平庸  | 触发奇遇概率加成——"普通人遇到怪事的概率反而最高" |
| 医生世家 | 治疗技能、异常诊断  | 战斗偏弱  | 能识别异常类型，知道哪些能治哪些不能         |
| 军警家庭 | 战斗力强、纪律性   | 灵活性低  | 右手和躯干基础数值高，但社交选项少          |
| 教师家庭 | 学习速度快、知识面广 | 体能一般  | 大脑基础数值高，技能升级经验减半           |
| 生意家庭 | 初始资金多、讲价能力 | 容易得罪人 | 能"投资"未来收益，在金涌效果翻倍          |

### 5.3 出身与组件的关系

出身影响哪些组件更容易触发异常变化：

| 出身类型  | 易异常组件    | 原因                        |
| ----- | -------- | ------------------------- |
| 军警家庭  | 右手、躯干    | "三代从军，右手天生就知道怎么握武器"       |
| 医生世家  | 大脑       | "从小看人体内部结构，有时能看到别人看不到的"   |
| 水客的后代 | 左手       | "摸过太多来路不明的东西，手记住了"        |
| 快递世家  | 双腿       | "跑全城跑多了，腿有了自己的想法"         |
| 烧鹅店世家 | 右手       | "三代人的火候，手比脑子先知道该怎么做"      |
| 普通人   | 全组件均匀低概率 | "没什么特别的，就是运气好——怪事偏偏爱找普通人" |

## 六、六组件身体系统（概念概述）

> **定稿设计见第二十三章（身体组件系统）和第二十二章（数值架构）。** 本章保留概念说明和异常示例，具体数值公式以定稿章节为准。

### 6.1 组件定义

角色身体拆分为6个独立组件，每个有自己的数值和装备位：

| 组件 | 装备位      | 主要功能   | 异常方向    |
| -- | -------- | ------ | ------- |
| 左腿 | 鞋/裤(左)   | 移动、闪避  | 移动行为异常  |
| 右腿 | 鞋/裤(右)   | 移动、稳定性 | 移动目的地异常 |
| 左手 | 手套/饰物(左) | 辅助、持物  | 触摸效果异常  |
| 右手 | 武器/手套(右) | 攻击、操作  | 使用效果异常  |
| 躯干 | 护甲/衣物    | 防御、生命  | 承受方式异常  |
| 大脑 | 头饰/饰品    | 技能、感知  | 认知效果异常  |

### 6.2 组件数值

每个组件有3项基础数值：

- **效能** — 该组件执行正常功能的效果
- **稳定** — 异常触发时的可控程度（高=可预测的异常，低=不可控的异常）
- **成长** — 该组件升级速度

### 6.3 异常变化示例

异常变化是搞笑的、戏剧性的，不是恐怖的。每个异常都是一个好笑的角色特征：

| 组件 | 异常名称 | 效果                                                                                                               | 触发场景     |
| -- | ---- | ---------------------------------------------------------------------------------------------------------------- | -------- |
| 左腿 | 绕路癖  | 移动时偶尔自动改道，多花时间但终点附近总能发现隐藏物品。你的腿对导航有自己看法。它曾带你穿过写字楼大堂、停车场、一家从没去过的粉店，然后到了你本来要去的地方。粉还挺好吃的。你后来再去找，找不到了。你左腿说它知道在哪，但不说。 | 探索时随机触发  |
| 右腿 | 扎根   | 受到攻击时有概率不后退反而定住，下次反击伤害+50%。你右腿觉得退让是懦弱。你右腿管不了你的嘴，但管得了你的脚。                                                         | 战斗中被攻击时  |
| 左手 | 空口袋  | 能从空口袋掏出东西，但永远不是你想要的——有时候反而有用。你不知道口袋连着哪。你掏出过一把钥匙，但不是任何一扇门的。你掏出过一张照片，照片上是你，但你没拍过这张照片。你掏出过一只袜子。                     | 战斗/探索均可  |
| 右手 | 停不住手 | 使用道具时有概率多使用一次（不消耗额外道具）。这个"概率"不是随机的——是你的右手觉得这次用得不够好，想再来一遍。它不是在帮你，它是在嫌你笨。                                          | 战斗中使用道具  |
| 躯干 | 反弹体质 | 受到的异常效果有概率反弹给来源。你身体不接受外来异常，原路退回。快递拒收。                                                                            | 被异常效果影响时 |
| 大脑 | 脑补   | 自动推断NPC没说的信息。准确率大概四成。剩下六成你会得出完全错误的结论，并且深信不疑。上次你推断茶餐厅老板在密谋什么，其实他只是便秘。                                             | 对话时随机触发  |

### 6.4 组件成长

- 组件通过**使用**成长——你用右手攻击多，右手效能就涨
- 组件通过**遭遇异常**变化——经历特定事件后可能获得异常
- 异常可以被**强化**或**抑制**——玩家可以选择发展方向
- 组件状态在**一代内有效**，角色身上的异常不跨代继承（装备上的异常可继承，详见第三十五章继承系统）

## 七、数值系统（概念概述）

> **定稿设计见第二十二章（数值架构）。** 本章保留概念说明和设计意图，具体公式和数值范围以第二十二章为准。

### 7.1 设计原则

数值系统服务于"角色是个什么样的人"，而不是"角色有多强"。数值不透明堆叠，而是通过组件、出身、异常的组合产生角色个性。

### 7.2 三层架构（概述）

定稿采用三层架构（详见第二十二章）：

- **Tier 1 — 组件层**：6 个身体组件各有效能/稳定/成长三项数值
- **Tier 2 — 基础属性层**：生命/精力/行动力/感知/机缘/韧性 + 桥接值力量（=双手均值）
- **Tier 3 — 衍生属性层**：攻击力/暴击率/暴击伤害/闪避率/命中率/减伤率/异常触发率（7 项）

> 注意：第七章早期版本中的属性定义和数值范围已被第二十二章取代。暴击率 = 异常爆发值，与力量挂钩。区域不碰属性链，只影响效果层。

### 7.3 数值展示

混合展示：基础属性显数字，衍生属性显百分比，异常修正显文字。详见第二十二章 22.5 节。

## 九、能力与战斗系统（概念概述）

> **定稿设计见第二十九章（战斗系统）和第二十五章（技能系统）。** 本章保留战斗选项、敌人台词和技能示例，具体机制以定稿章节为准。

### 9.1 战斗概述

- **模式**: 回合制
- **队伍**: 1-3人小队（详见第二十九章战斗系统）
- **站位**: 前排/后排，影响受击和技能范围
- **无元素克制**: 没有火克冰——效果取决于上下文

### 9.2 回合结构

```
回合开始 → 状态结算 → 玩家行动选择 → 执行行动 → 敌方行动（带台词） → 回合结束
```

每回合核心选择不是"攻击/防御/技能/道具"的标准菜单，而&#x662F;**"你要怎么跟这个不正常的处境互动"**。选择本身是叙事性的：

**战斗选项示例:**

- 直接应对（对应"攻击"）— "上去就是干"
- 装作没事（对应"防御"，但有概率让异常"真的不存在了"）— "这很正常。什么都没发生。我没看见。"
- 用身上的东西试试（对应"道具"，但效果取决于区法则）— "试试这个？我也不知道会发生什么"
- 说点什么（对应"技能"，但内容是角色性格驱动的话语）— "你张嘴了。你自己都不知道要说什么。"
- 跑（对应"逃跑"，但路可能不是你来选——右腿异常时）— "走为上策。但往哪走是个问题。"

### 9.3 敌人台词系统

每个敌人都有性格鲜明的战斗台词。敌人在行动时会说话，被打会说话，被打败还会说话。台词是搞笑的核心载体：

**不存在的同事**（敌方回合）

> "你那个attack的deck我看了，要不要align一下？我约了个15分钟的slot，你打我的时候顺便过一下？"

**不存在的同事**（受到攻击）

> "OK所以这个feedback我记一下——被打的时候没有pre-mortem，下次可以优化。"

**迷路的外卖**（受到攻击）

> "我只是想送到5栋！5栋在哪！你知道5栋在哪吗？！你打我也没用我不知道5栋在哪啊！！"

**迷路的外卖**（被打败）

> "终于……5栋……是这栋吗……"（消散）

**夜市活过来的炒粉**（发动技能）

> 炒粉朝你泼了一勺滚油。你闪开了。炒粉很失望。它又泼了一勺。这次没泼你，泼了旁边的不存在的同事。同事消失了。炒粉沉默了一下，看了看锅铲，好像在思考人生。

**走错路的导航**（敌方回合）

> "前方200米右转。前方100米右转。前方50米右转。您已到达目的地。"  
> 你看了一眼四周。这不是目的地。这是一面墙。  
> "您已到达目的地。"  
> 它很坚持。

**走错路的导航**（被打败）

> "路线已重新规划。请调头。请调头。请调——"（消散）

### 9.4 技能设计

没有技能树。技能是从异常遭遇中捡来的生存经验，效果取决于上下文。

**技能示例:**

| 技能    | 来源   | 效果                             | 区域影响     |
| ----- | ---- | ------------------------------ | -------- |
| 室内打伞  | 异常遭遇 | 触发"不该有的后果"——具体是什么取决于在哪个区       | 每区效果不同   |
| 说梦话   | 异常遭遇 | 说一句不连贯的话，有概率让敌人的"现实认知"短暂崩溃     | 无区域差异    |
| 假装没看见 | 异常遭遇 | 对正在发生的异常装作没注意到，有概率让它真的不存在了     | 野坪效果增强   |
| 讲价    | 金涌出身 | 可以跟任何东西讲价——包括敌人的攻击力、时间流速、自己的伤势 | 金涌效果翻倍   |
| 调试    | 云墩出身 | 能"暂停"一个异常效果一回合                 | 云墩额外恢复精力 |
| 火候    | 禾塘出身 | 火焰相关控制，能"烧掉"某些异常效果             | 禾塘范围扩大   |

### 9.5 敌人设计方向

敌人不是"史莱姆""哥布林"之类的标准RPG怪物，而是"不对劲的东西"：

| 敌人类型      | 描述                             | 出现区域  | 台词味道                             |
| --------- | ------------------------------ | ----- | -------------------------------- |
| 迷路的外卖     | 一份外卖自己走在路上，找不到收件人。攻击方式是往你身上泼   | 全城    | "我只是想送到5栋！5栋在哪！你知道5栋在哪吗？！"       |
| 不存在的同事    | 一个你不认识的"同事"非要跟你开会。攻击方式是无尽的工作要求 | 金涌、云墩 | "你那个attack的deck我看了，要不要align一下？"  |
| 电梯里的第七层   | 不是生物，是一个空间异常。你被关在一段不停重复的电梯旅程里  | 高楼密集区 | （无台词，只有电梯提示音不断重复"7楼到了"）          |
| 夜市里活过来的炒粉 | 一份炒粉不愿意被吃掉。攻击方式是烫你             | 钟岭、旧墟 | （无台词，但动作有戏剧性——泼油、沉思、看锅铲）         |
| 集装箱里的东西   | 没人知道是什么。它只是在那里，让你很不舒服          | 盐澳    | （无台词，但你会收到它的"感受"，像一段不属于自己的记忆）    |
| 山里的老东西    | 非常古老的存在。不是恶意的，但它的存在本身就让周围不正常   | 野坪、潮湾 | "你来了。坐。"（然后它跟你下棋。你不确定你是不是在跟它下棋。） |
| 走错路的导航    | 一个导航语音非要带你去一个不存在的地方。攻击方式是让你迷路  | 全城    | "前方200米右转。您已到达目的地。"（你面前是一面墙）     |

> **设计原则**: 敌人是搞笑的、日常化的、有性格的。不是恐怖的。打赢了不只有经验，还有故事。每个敌人至少有一句让人记住的台词。

## 十、任务与遭遇系统（概念概述）

> **定稿设计见第三十三章（事件与任务系统）。** 本章的任务分类是叙事层面的主题分类，第三十三章定义了 7 种机制层面的任务类型（生存/探索/社交/传承/异常/休闲/地牢），两者互补。

### 10.1 设计原则

任务不是"杀10只史莱姆""找NPC送东西"。任务是你在城市中撞上的"不对劲"。

### 10.2 任务类型

| 类型   | 描述            | 示例                                                   |
| ---- | ------------- | ---------------------------------------------------- |
| 异常调查 | 调查某件不对劲的事     | "金涌一栋写字楼的电梯按7楼到一间不该存在的办公室。里面有人请你帮忙——但帮完之后你不确定你到底帮了谁" |
| 人情委托 | NPC请你帮忙处理一些怪事 | "云墩某个路口的监控拍到了你的未来。有人出高价买这段录像。你卖不卖？"                  |
| 城市传说 | 追踪一个都市传说      | "钟岭地铁末班车后还有一班不在时刻表上的车。坐上去的人第二天正常醒来，但总觉得忘了什么重要的东西"    |
| 日常纠纷 | 看起来正常的事，但有点不对 | "旧墟东墟一个地摊在卖你的童年照片。你从没在这里拍过照。摊主说这是你寄卖的——你不记得有这回事"     |
| 跨区事件 | 涉及多个区的连锁事件    | "禾塘农场种出了一种没见过的作物。吃了的人想去盐澳港。到了港口的人想上某条船。船上有什么？"       |

### 10.3 Roguelike 随机事件

每次进入一个区，随机生成该区类型的异常事件。事件有：

- **好坏随机** — 同一事件可能给你好处也可能给你麻烦
- **上下文依赖** — 你的出身、组件异常、装备都会影响事件走向
- **连锁效应** — 某些事件会影响后续事件池

## 十一、继承系统（概念概述）

> **定稿设计见第三十五章（继承系统）。** 本章保留设计意图和叙事内容，具体继承清单和规则以第三十五章为准。

### 11.1 设计意图

继承系统是"多代经营"的核心驱动力。每一代角色死亡后，积累的部分内容传递给下一代，让玩家感觉家族在成长、城市在认识你。

> 注意：早期版本中的"血脉天赋（选1个异常固化）""金钱不传""城市好感度（隐藏值）"等设计已被第三十五章取代。定稿规则：技能配方/装备/道具/金钱(扣遗产税)/房产(概率)/声望/区知识/共鸣碎片可继承；角色属性/任务进度/角色异常/体重不继承。

### 11.2 NPC跨代记忆系统

NPC对玩家家族的态度不是重置的，而是**累积的**。这是"做客→成为地头"核心体验的关键载体：

- 每个NPC有一个"家族熟悉度"值，跨代保留
- 熟悉度越高，NPC对话越随意、越不客气（"又来了？"取代"您好"）
- 部分NPC会随代际自然更替（老去、离世、后代接手），但记忆传承给后代
- 某些NPC的"空位"（已故NPC常坐的位子、常站的角落）会保留，成为家族记忆的锚点

> 详细机制见第三十五章 35.6 节（NPC跨代记忆）。

### 11.3 家族日志

每代故事自动记录摘要，玩家可编辑标题。家族日志在结局时回放，是多代叙事的情感载体。

## 十二、人生阶段系统（概念概述）

> **定稿设计见第三十四章（生命周期系统）和第二十二章 22.4 节（年龄曲线）。** 本章保留概念说明，具体机制以定稿章节为准。

### 12.1 阶段定义

| 阶段 | 年龄 | 可控动作/年 | 核心机制 | 玩家控制度 |
| -- | -- | ------- | ------ | ------ |
| 婴儿 | 0-5 | 0（自动） | 关键选择 + 突发事件 | 极低（第二代起跳过） |
| 童年 | 6-12 | 4 | 二级菜单 + 无厘头选项 | 低 |
| 少年 | 13-18 | 10 | 首次自由行动，异常事件教学 | 中 |
| 青年 | 19-35 | 14 | 核心冒险期，组队、战斗、任务 | 高 |
| 壮年 | 36-65 | 14 | 能力巅峰，高难度挑战，培养后代 | 高 |
| 中年 | 66-80 | 14 | 传授经验，家族经营 | 中（部分能力下降） |
| 老年 | 81+ | 14 | 属性衰退，传承准备，最终事件 | 中（HP 流速加速） |

### 12.2 阶段过渡事件

每次进入新阶段时有过渡事件，类似"生日"概念：

- **6 岁** — "你开始记事了"（童年期开始，第二代起这是游戏实际开始点）
- **13 岁** — "你第一次注意到了什么不对劲"（教学事件）
- **19 岁** — "你该出去看看了"（开放全城探索，可结婚）
- **36 岁** — "你不再是一个人了"（后代出生/加入）
- **66 岁** — "有些东西该传下去了"（传承重心）
- **81 岁** — "最后的故事"（HP 流速加速，最终事件触发）

> 详见第三十四章（生命周期系统），包括摸鱼机制、体重系统、婚姻与生育、死亡与延寿道具等。

## 十三、结局系统（叙事设计）

> **定稿机制见第三十七章（Roguelike 与结局系统）。** 本章保留叙事内容和结局场景设计，具体结局类型和触发条件以第三十七章为准。

### 13.1 核心内核：做客

鲲城是移民城市。几乎所有人都是"来鲲城的"。在一个所有人都是客人的城市里，**一个住了好几代的家族本身就是最大的异常。**

玩家驱动力不是"打倒魔王"，&#x662F;**"从客人变成自己人"**。每一代的冒险，是不知不觉地在跟这座城市建立关系。城市对家族的态度，随着代际推进而变化——从冷漠、到试探、到不要脸、到一起吐槽新人。

### 13.2 "成为地头"是什么意思

核心翻转：**成为地头不是城市对你变温柔了，是城市开始对你不要脸了。** 陌生人之间客客气气，自己人才互相整。你越本地，城市整你越狠——但整得越熟，越好笑。

同样一个"电梯按7楼到不该存在的办公室"事件，不同代际的体验完全不同：

| 代际  | 城市态度 | 事件表现                                                    | 玩家感受            |
| --- | ---- | ------------------------------------------------------- | --------------- |
| 第1代 | 查你证件 | 电梯把你扔到一间阴森办公室，里面的人看你的眼神像看闯入者                            | "这是什么鬼地方？"      |
| 第3代 | 有点面熟 | 电梯还是到7楼，但办公室里有人跟你打招呼了——"哦，你是老X家的？你爸以前也被扔到这儿来"           | "又来了，但好像没那么可怕了" |
| 第5代 | 给你办卡 | 电梯送你到7楼，门上贴了张纸条——"老X家专用，别的人别按"。但你还是被扔到7楼。这卡就一个用途。       | "行了行了，7楼就7楼"    |
| 第8代 | 不装了  | 你按1楼，电梯直接跳过，显示"7楼到了，别装了"。你叹口气。旁边第1代的NPC被吓个半死，你跟他说"习惯就好" | "我是不是该搬去7楼住"    |

### 13.3 NPC跨代记忆

NPC对玩家家族的态度随代际变化。这是"做客→扎根"的核心体验载体：

**茶餐厅老板的跨代表现：**

- **第1代**：不搭理你。你点餐他头都不抬。
- **第3代**："你妈以前也爱点这个。"你不知道他怎么知道的。
- **第5代**：老板孙子追你——"你别坐这个位子！这是给我留的！你爷爷以前坐这儿不代表你能坐！"你们为了一个位子吵起来，但吵的是辈分问题。
- **第8代**：老板孙子已经接手了店，看到你就说"又来了？你爸欠的炒粉钱还没还呢，连利息算下来你这辈子还不完了。"然后还是给你端了一份。

有些NPC会从"陌生人"变成"老熟人"再变成"看着你长大的长辈"——然后在某一代理所当然地老去、不在了。那个位子以后空着，但茶餐厅老板的孙子还是会在那个位子上放一杯你爷爷爱喝的。

### 13.4 城市试探事件

某些事件表面上是随机遭遇，实际上是城市在试探你"是不是要留下"。这些事件**全部写成搞笑的**：

**莫名其妙的罚单**

> 收到一张罚单。车不是你的，地址不存在，日期是你出生前三年。交罚款还是去申诉？
>
> - 交罚款 → 城市觉得你是好糊弄的外来户
> - 去申诉 → **这才是地头。** 地头会为了一张莫名其妙的罚单跟系统死磕到底。申诉成功（当然成功不了，罚单日期在你出生前），但你获得"较真"特质，城市对你的好感+1

**鲲通卡多了三千块**

> 你的鲲通卡里突然多了三千块，交易记录显示"盐澳港集装箱7号"。花不花？
>
> - 花了 → 被记一笔。以后城市找你"帮忙"时理直气壮："你拿了好处不办事？"
> - 不花 → 城市觉得你这人还行。但三千块一直在卡里，每次打开钱包都看着你

**楼下多了个公交站**

> 你家楼下突然多了个公交站，站名叫你的名字。但车从来不靠站。投诉还是等？
>
> - 投诉 → 投诉无果。但投诉的过程本身被记录在家族日志里："第4代，为楼下不存在的公交站打了17个投诉电话。"
> - 等 → **等的才是地头。** 地头等的不是公交，是一个说法。等够了一定天数，某天真的来了一辆车。车停下来，门开了，里面是空的。司机位也没人。但车确实停了。

### 13.5 结局："成为地头"认证场景

> 以下为"成为地头"结局的叙事场景设计。定稿的 5 种结局类型和触发条件见第三十七章 37.3 节。

当家族在11区都积累了足够的"根"（通过跨代事件、NPC关系、异常经历），触发结局事件。

**结局场景：**

城市给你办了个仪式。地点在滨海大道高架桥下面那个停车场。凌晨两点。出席人员：你，一只可能是市长的鸽子，和四袋没拆封的宵夜。

鸽子（可能是市长）叼来一张纸。上面写着"地头认证"。你的姓打对了，名打错了。过塑过歪了，右上角翘着。

你看了看证书。看了看鸽子。看了看高架桥。

"就这？"

"就这。"

"8代人，就一张过塑过歪了的纸？"

"还有一个车位。"

你看了看车位。在鸟巢正下方。

"这车位……"

"地头车位。你看看哪个地头车位不在鸟巢底下。"

远处一辆末班车驶过，没靠站。你知道那班车。你曾祖父坐过。

你把证书塞进口袋。过塑的角扎了你一下。

你是地头了。

### 13.6 结局后的"新手村"

> Meta 进度系统（跨 run 永久解锁）详见第三十七章 37.5 节，包括天敌铸造系统和永久解锁内容。

通关后，城市开始**跟你抱怨新来的**——

> "现在这些新异常，一点素质都没有。以前电梯到7楼，好歹办公室里有人给你倒杯茶。现在的异常呢？把你扔到7楼，空的，连个鬼都没有。一代不如一代。"

你成了那个说"以前更好"的人。**这才是真正的地头标志**——不是被城市接纳，是开始跟城市一起吐槽。

如果玩家选择"再玩一圈"（New Game+），下一周目以"地头后代"身份开局。NPC态度更熟络，异常事件更离谱（因为城市跟你更不客气了），但某些隐藏内容因为你是"地头"才解锁——比如茶餐厅那个一直空着的位子，现在你可以坐了。

### 13.7 双层激励结构

| 层级  | 动力               | 体验                |
| --- | ---------------- | ----------------- |
| 表层  | 继承系统：每代比上代更强     | "再来一代，这次我要选不同的出身" |
| 深层  | 做客系统：每代城市对你态度变一点 | "下一代会遇到什么更离谱的事？"  |
| 通关后 | 地头模式：城市跟你一起吐槽新人 | "再来一圈，看看还有什么没见过的" |

### 13.8 与旧方案的区别

| 维度   | 旧方案（鲲城脉动） | 新方案（做客）        |
| ---- | --------- | -------------- |
| 内核   | 远古魔法汇聚点   | 移民城市的归属感       |
| 隐藏机制 | 共振值计数器    | NPC跨代记忆+城市态度变化 |
| 结局感  | 史诗感、命运感   | 荒诞感、"就这？"感     |
| 鲲城关联 | 换个城市一样成立  | 离开鲲城不成立        |
| 调性   | 偏严肃、偏温情   | 搞笑、市井、不要脸      |
| 玩家动力 | "我要知道真相"  | "下一代会怎样"       |

## 十四、Roguelike 机制（概念概述）

> **定稿设计见第三十七章（Roguelike 与结局系统）。**

### 14.1 核心不可预测性

不是来自"随机地图"（地图是固定的鲲城11区），而是来自：

1. **随机法则偏移** — 每局开始时，各区的异常法则有随机微调
2. **随机异常事件** — 每次进入区域随机生成事件
3. **随机组件异常** — 同一出身每局获得的异常不同
4. **随机道具效果** — 同一道具在不同局、不同区效果不同

### 14.2 随机种子

> 详细机制见第三十七章（Roguelike 与结局系统）。

种子在整个 run（8 代）期间**锁定不变**，保证世界连贯性。换 seed = 新 run。

种子决定：
- 各区异常法则偏移方向
- 事件池抽取顺序
- 异常获得的随机性

### 14.3 死亡不是终点

角色死亡不是"Game Over"，而是自然的人生节点。继承系统让死亡变成叙事钩子。死亡后可选择"留下"（正常继承）或"离开"（下代从零开始，无继承）。详见第三十七章 37.2 节。

## 十五、美术与音频方向

### 15.1 美术风格

- **像素风** — 32x32 或 48x48 基础精灵
- **色调** — 明亮、日常、生活化。异常元素用微妙的不协调感暗示，不靠暗黑滤镜
- **地图** — 鲲城各区简化像素地图，保留地标辨识度
- **角色** — 像素小人，组件变化有视觉反馈（异常后的腿/手有外观变化）

### 15.2 音频方向

- **BGM** — 轻快的日常曲调为主，异常事件时音乐微妙变调
- **音效** — 日常化音效（地铁声、炒粉声、海浪声）+ 异常时的不和谐音
- **配音** — 无配音，纯文字对话

## 十六、技术架构（概要）

### 16.1 技术栈

| 层    | 技术                  |
| ---- | ------------------- |
| 渲染   | HTML5 Canvas 2D     |
| 逻辑   | JavaScript (ES6+)   |
| 桌面打包 | Electron            |
| 数据格式 | JSON（角色、道具、事件数据驱动）  |
| 存档   | LocalStorage + 文件导出 |

### 16.2 核心模块（预览）

```
src/
  engine/          — 游戏引擎核心
    renderer/      — Canvas 渲染层
    input/         — 输入处理
    scene/         — 场景管理
  game/
    player/        — 角色系统（组件、属性、异常）
    combat/        — 战斗系统
    map/           — 地图与探索
    dialogue/      — 对话系统
    event/         — 事件系统（Roguelike 随机事件）
    inheritance/   — 继承系统
    lifecycle/     — 人生阶段管理
  data/
    districts/     — 11区数据
    origins/       — 出身数据
    items/         — 装备道具数据
    enemies/       — 敌人数据
    events/        — 事件数据
  ui/              — UI 组件
  electron/        — Electron 主进程
```

### 16.3 数据驱动

所有游戏内容（出身、道具、敌人、事件）使用 JSON 数据文件定义，代码只负责引擎逻辑。这样可以快速迭代内容而不需要改代码。

## 十九、文案风格指南

本章是所有游戏内文案的写作标准。从异常描述到系统提示，从NPC对话到升级通知，全部按此标准执行。

### 19.1 核心原则

1. **好笑优先** — 每段文案至少一个笑点。没有笑点的文案 = 不合格的文案
2. **美式幽默 + 无厘头** — 社会讽刺（《南方公园》）+ 日常荒诞（《脱口秀大会》）+ 打破第四面墙（《银魂》）
3. **不煽情** — 温情可以有，但不能主动催。感动是玩家自己感受到的
4. **荒诞但自洽** — 设定可以离谱，离谱内部要有逻辑
5. **系统有人味** — 系统提示不是机器播报，是一个嘴贱但靠谱的朋友在给你解说

### 19.2 异常描述风格

异常描述 = 一段角色特征白描。要有画面感、有笑点、有"这角色我认识"的感觉。

**模板：**

> **[组件]·[异常名]**  
> [一句话概括效果]。[2-3句展开，用具体场景说明，最后一个场景带反转或笑点]。

**范例见第六章6.3节。**

### 19.3 道具/装备描述风格

道具描述 = 物品说明 + 一段"它出了什么问题"的轶事。信息要给够（玩家知道这东西干什么用），但给法要好笑。

**模板：**

> [物品名]  
> [基础信息：数值/类型/余额等]  
> [1-2句异常描述：这东西哪里不对]  
> [1句备注或吐槽]

**范例见第八章。**

### 19.4 敌人台词风格

每个敌人至少3句台词：行动时1句、受击时1句、败退时1句。台词要体现敌人"是什么东西"的性格。

**标准：**

- 迷路的外卖 → 所有台词都在问路
- 不存在的同事 → 所有台词都是职场黑话
- 走错路的导航 → 所有台词都是导航语音，但内容荒谬
- 夜市炒粉 → 无台词，用动作描写（泼油、沉思、看锅铲）
- 山里的老东西 → 台词极少，但每句都有分量

### 19.5 系统提示风格

系统提示要有人味。不是"您的躯干效能提升了"，而是一个朋友在跟你说话。

**升级提示范例：**

> **升级！**  
> 你的躯干效能提升了。具体怎么提升的别问，反正挨打的时候少疼一点。  
> 你的大脑效能提升了。你现在能多记住一个NPC的名字。就一个。别贪。

**继承画面范例：**

> **第3代·陈小明 寿终**
> 享年74岁。死因：在野坪山里跟一个老东西下棋下到自然死亡。赢了。
>
> 继承内容（详见第三十五章）：
>
> - 技能配方：调试（学习难度减半，已叠加2代 = 原难度的25%）
> - 传承装备：鲲通卡（耐久7折，余额¥12.00，怨气余额充足）
> - 金钱：¥3,400（扣除10%遗产税后）
> - 家族声望：旧墟茶餐厅老板还记着你们家欠的¥50
> - 共鸣碎片：7个
> - 房产继承判定：烂尾楼（你继承了一间停工楼盘的产权，无法入住。也许下一代能用上。）
> - 家族日志新增一条："第三代，在野坪下棋的时候死了。他赢了。我们不确定赢了什么。"

### 19.6 NPC对话风格

NPC说话要有口音、有职业特征、有性格。不要所有NPC一个腔调。

- 茶餐厅老板 → 粤式普通话，短句，爱搭不理但什么都看在眼里
- 程序员NPC → 中英夹杂，把一切比喻成代码
- 城中村房东 → 大嗓门，直接，什么都用钱衡量但人其实不坏
- 夜市摊主 → 神秘但接地气，说一半留一半
- 老东西（野坪） → 极简，每句话都像下了判决

### 19.7 结局文案风格

结局不煽情、不史诗。用"就这？"的反高潮制造记忆点。越重要的时刻越轻描淡写，反差本身就是笑点和泪点。

**核心句式：**

- "就这？" — 玩家说的
- "就这。" — 游戏/城市回的
- 然后一个细节扎你一下（过塑的角扎了你一下）

### 19.8 文案审核清单

每段文案提交前，过一遍：

- [ ] 读完笑了（或至少嘴角动了）？
- [ ] 有没有一句值得截图发讯圈的话？
- [ ] 有没有在煽情？（有就删）
- [ ] 信息给够了？（玩家知道发生了什么、该干什么）
- [ ] 语气统一？（不像换了个人写的）

## 二十、异常展开系统

### 20.1 概述

异常物品/装备拥有「异常展开层级」（Anomaly Unfolding Level, AUL），范围 1-9。每次在战斗中使用该物品时，有概率使异常层级上升。每上升一层，物品的数值效果增强，同时获得新的 buff 和 debuff。

核心张力：**越用越强，越强越疯。**

设计目的：为指数爆炸的数值体系提供存在的理由——部分「天敌」需要异常展开积累爆发力才能挑战（详见第二十一章）。但天敌并非全部依赖异常展开，有些靠属性门槛，有些靠策略，有些靠特定道具。异常展开是工具之一，不是唯一答案。

### 20.2 装备稀有度与展开上限

6 级稀有度，决定异常展开上限（详见 8.4 节）：

| 稀有度    | 颜色 | 展开上限 | 定位         |
| ------ | -- | ---- | ---------- |
| 普通     | 白色 | 3    | 日常用品，略微不对  |
| 不对劲    | 蓝色 | 4    | 有明确异常，可控使用 |
| 出问题了   | 紫色 | 5    | 异常外溢，影响周围  |
| 离谱了    | 金色 | 6    | 现实开始投诉     |
| 要命了    | 红色 | 7    | 物品自行决策     |
| 已经无所谓了 | 黑色 | 9    | 物品与使用者融合   |

### 20.3 展开机制

**层级上升概率：**

- 基础概率：每回合 15%
- 每已展开层级 +3%（1→2: 15%, 2→3: 18%, 3→4: 21%, 4→5: 24%, 5→6: 27%, 6→7: 30%, 7→8: 33%, 8→9: 36%）
- 机缘修正：最终概率 = 基础概率 × (1 + 机缘/100)
- 达到该稀有度上限后不再上升

**数值倍率（指数爆炸）：**

| 展开层级 | 数值倍率  | 副作用强度 | 定性描述   |
| ---- | ----- | ----- | ------ |
| 1    | ×1.0  | 无     | 正常     |
| 2    | ×1.5  | 轻微    | 有点不对   |
| 3    | ×2.0  | 轻微    | 明显不对   |
| 4    | ×3.0  | 中等    | 开始影响他人 |
| 5    | ×4.5  | 中等    | 环境异变   |
| 6    | ×7.0  | 严重    | 现实投诉   |
| 7    | ×11.0 | 严重    | 物品自主行动 |
| 8    | ×18.0 | 极重    | 边界模糊   |
| 9    | ×30.0 | 灾难级   | 融合     |

**每次展开发生什么：**

1. 物品基础数值（攻击力/防御力/效果值等）乘以对应倍率
2. 获得一个新的 buff（正面效果，与物品主题相关）
3. 获得一个新的 debuff（负面效果，是 buff 的代价或失控表现）
4. 物品描述更新，反映当前状态
5. 触发一条战斗日志（搞笑文案）

**展开在战斗结束后：**

- 展开层级在战斗结束后重置为 1
- 但部分高稀有度物品可能有「残留」效果（待定）

### 20.5 与数值系统的关系

异常展开直接影响 Tier 3 衍生属性：

- 展开层级提升 → 物品提供的衍生属性加成 ×倍率
- 展开带来的 buff/debuff 是独立于属性之外的临时战斗修正
- 机缘影响展开概率 → 机缘高的角色异常展开更快，但副作用也来得更快

这意味着：**机缘高的角色是高风险高回报型**——异常物品在他们手里展开更快，爆发力更强，但也更容易失控。

## 二十一、天敌遭遇（概念设计）

> **定稿设计见第三十二章（敌人系统），特别是 32.5 节（天敌具象化，34 种全部完成）。** 本章保留设计理念和示例，完整天敌列表以第三十二章为准。

### 21.1 设计理念

天敌不是"数值天花板"。它们不是用更高稀有度的物品去打更大数字的怪——那种设计会变成装备竞速。

天敌是**机制谜题**。每个天敌有独特的胜利条件，不是简单的"打空血条"。你可能遇到只有 1 滴血但永远打不死的对手，也可能遇到血条无限只能闪避的对手，甚至遇到根本看不见血条的对手。

**核心原则：**

- 天敌出现在特定**人生阶段**，不是跟随你一生升级
- 不同**出身**可能遇到不同的天敌
- 天敌可以**重复出现**（如早高峰天天遇到）
- 天敌不一定需要异常展开——有些靠属性，有些靠策略，有些靠特定道具
- 天敌不是必须击败的——但绕过有代价

### 21.2 天敌类型

按胜利条件分为 6 种类型：

| 类型    | 核心机制                 | 举例     |
| ----- | -------------------- | ------ |
| 属性门槛型 | HP极低，但需要特定属性达标才能造成伤害 | 校园霸凌   |
| 无限生存型 | HP无限，只能闪避/生存，失败有惩罚   | 早高峰4号线 |
| 隐藏条件型 | 看不见血条，达成特定状态后可见      | 期末考试   |
| 限时爆发型 | 限时回合内打出足额伤害          | 扎根积分系统 |
| 资源消耗型 | 不以HP为核心，消耗你的资源       | 房东     |
| 镜像型   | 复制你的能力，需要策略破解        | 论文查重   |

### 21.3 天敌示例

> 以下为设计示例。完整 34 种天敌（全部具象化）见第三十二章 32.5 节。示例中使用早期抽象名称，定稿版本中每个天敌均已具象化（如"校园霸凌"→"楼梯口的六年级"）。

- 出现阶段：童年期（6-12岁）
- 出现条件：学校事件触发，所有出身都可能遇到
- HP：1

- 台词风格：小学生挑衅语气，幼稚但扎心
- 范例台词："你打人跟没吃饭一样。哦你确实没吃早饭。"
- 设计意图：不是打不过，是不敢打。韧性 = 敢不敢还手
- 幽默反转：击败后霸凌者说"好吧好吧我们做朋友"然后立刻偷你午饭钱

**天敌 2：期末考试**

- 类型：隐藏条件型
- 出现阶段：少年期（13-18岁）
- 出现条件：学校线事件
- HP：???（隐藏）
- 机制：血条不可见，所有攻击显示"miss"。需要进&#x5165;**「专注」状态**（连续使用大脑组件行动 3 次不中断）后血条显现，此时 HP 只有 20，正常输出即可击败
- 失败/绕过：不专注直接攻击 5 回合后，考试自动结束，成绩按"瞎蒙"计算（随机通过/不通过）
- 台词风格：试卷语气，每句话都是选择题
- 范例台词："以下哪个选项描述了你现在的处境？A.完蛋 B.彻底完蛋 C.完蛋但带有创新性 D.以上皆是"
- 设计意图：你看不见考试的血条，因为你没在专注

**天敌 3：早高峰4号线**

- 类型：无限生存型
- 出现阶段：少年期至壮年期（通勤阶段反复出现）
- 出现条件：需从钟岭/金涌通勤时触发
- HP：∞（无限）
- 机制：无法造成伤害。每回合地铁"挤压"攻击，必须闪避。闪避成功 = 前进一站，闪避失败 = 迟到。需要存活 5 回合（5 站）到达目的地
  - 闪避判定：行动力 + 感知 衍生的闪避率
- 失败惩罚（迟到）：当日所有收入归零 + 获得 debuff「emo」(全属性-10%，持续 1 天)
- 台词风格：地铁广播语音，内容荒谬但语气专业
- 范例台词："本次列车满载率137%。您的脾脏正在与陌生人手肘发生非自愿接触。下一站：你的极限。"
- 设计意图：有些仗你打不赢，你只能撑过去
- 特殊：持有「鲲通卡」装备并异常展开时，每展开 1 层减少 1 站需生存回合数

**天敌 4：相亲对象**

- 类型：隐藏条件型
- 出现阶段：青年期（19-35岁）
- 出现条件：社交事件，部分出身更容易触发
- HP：???（隐藏）
- 机制：血条不可见。"直接应对"造成 0 伤害且增加「尴尬值」，尴尬值满 = 相亲失败。需要使&#x7528;**"说点什么"**&#x6210;功 3 次（说对话）后，对方"打开心扉"，血条显现（HP: 15），此时一个"说点什么"即可"成功"
- 失败/绕过：尴尬值满后相亲失败，获得 debuff「自我怀疑」(机缘-5，持续 3 天)。可以中途"跑"，但获得「社死」debuff (该区 NPC 好感度获取-50%，持续 3 天)
- 台词风格：尴尬的寒暄，每句话都在试探
- 范例台词："你平时……有什么爱好吗？（沉默）哦……打游戏啊。嗯。……挺好的。"
- 设计意图：有些对手你不能用拳头解决

---

**天敌 5：论文查重系统**

- 类型：镜像型
- 出现阶段：青年期（19-35岁）
- 出现条件：云墩·大学城出身，或学术线事件
- HP：200
- 机制：**重复行动伤害衰减**。每个行动首次使用造成正常伤害，第二次使用伤害减半，第三次及以上伤害为 0（"查重率 100%"）
- 破解：5 种战斗行动（直接应对/装作没事/用东西/说点什么/跑）各使用至少 1 次后，查重系统"发现无法比对"而崩溃
- 失败/绕过：8 回合内未打出足够变化 → 查重不通过，获得 debuff「学术污点」(感知-5，持续到本代结束)
- 台词风格：学术论文审稿人语气，每句话带引用标注
- 范例台词："你的攻击模式与上一回合相似度 78% (Wang et al., 2024)。学术诚信违规。建议重修。"
- 设计意图：原创性。你不能重复自己

---

**天敌 6：房东**

- 类型：资源消耗型
- 出现阶段：壮年期（36-65岁）
- 出现条件：居住事件，城中村区域
- HP：无（不以HP为核心）
- 机制：
  - 房东没有血条。每回合发生两件事：① 永久降低最大生命值 8%（不可恢复）② 要求支付房租（金额随回合递增）
  - "胜利"条件：付清累计房租总额（如 5000 元）或存活 8 回合（租约到期）
  - "直接应对" = 拒绝交租（房东怒气+1，3 怒气后驱逐你 = 失败）
  - "说点什么" = 讲价（有概率降低本回合房租）
  - "用东西" = 交房租（消耗金钱）
- 失败惩罚：被驱逐 → 搬家 → 换区（当前区好感度-10，获得「居无定所」debuff）
- 台词风格：大嗓门，直接，什么都能用钱衡量
- 范例台词："房租涨了。又涨了。在你读这句话的时候又涨了。什么？你说合同？合同是给守规矩的人的。"
- 设计意图：你杀不死房东，你只能交钱或搬走

---

**天敌 7：税务稽查**

- 类型：资源消耗型
- 出现阶段：壮年期（36-65岁）
- 出现条件：金涌·金融出身，或高收入事件
- HP：300
- 机制：每回合抽走当前金钱的 15%。金钱归零 = 破产 = 失败。同时正常战斗，需打出 300 伤害
- 破解：在金钱归零前打出 300 伤害；或持有特定道具「假发票」可一次性重置抽税
- 失败惩罚：破产 → 失去当前所有金钱 + 获得「信用不良」debuff（全阶段购物价格+30%）
- 台词风格：税务员语气，每句话引用条文编号
- 范例台词："根据第四十七条第三款，你的战斗收入需缴纳45%的惊喜税。滞纳金从你听到这句话的那一刻开始计算。"
- 设计意图：有些对手不想要你的命，想要你的钱

---

**天敌 8：996加班制度**

- 类型：限时爆发型 + 资源消耗
- 出现阶段：中年期（66-80岁）
- 出现条件：云墩·科技园出身，或职业线事件
- HP：500
- 机制：每回合加速衰老 5 岁。当前年龄 + 回合数 × 5。年龄超过当前阶段上限 = 过劳死 = 失败。需要在"老死"前打出 500 伤害
- 破解：异常展开系统——需要在中年阶段积累足够的高稀有度物品并展开到高层级（红色物品层级 7+），才能在有限回合内输出 500 伤害
- 失败惩罚：过劳死 = 非正常死亡（提前进入继承阶段，本代成长减半继承）
- 台词风格：HR 语气，永远在"为你好"
- 范例台词："现在是晚上11点。你为什么还在打？哦你喜欢打是吧。好的那明天继续。后天也继续。你的工位需要更换吗？我看你好像快长在工位上了。"
- 设计意图：时间就是命。这是异常展开系统最直接的使用场景

---

**天敌 9：中年危机**

- 类型：隐藏条件型
- 出现阶段：中年期（66-80岁）
- 出现条件：随机触发，所有出身
- HP：???（隐藏）
- 机制：血条不可见。条件：你的 6 个组件中需要有**至少 3 个拥有异常**（你需要足够"奇怪"才能与中年危机对话）。满足条件后血条显现（HP: 100），但战斗中每回合随机一个组件的异常效果反转（buff 变 debuff）
- 失败/绕过：不满足条件时 5 回合后自动消退，但获得 debuff「存在焦虑」(全属性-5，持续到本代结束)
- 台词风格：哲学系大二学生语气，每句话都是存在主义拷问
- 范例台词："你快乐吗？不，不是问你今天快乐吗。我是问你，这个'你'，快乐吗。等等你还在打我？你连这个问题都没想清楚你打什么呢？"
- 设计意图：正常的人无法与中年危机对话。你得足够奇怪才行

---

**天敌 10：孩子叛逆期**

- 类型：属性门槛型
- 出现阶段：中年期（66-80岁，需要有后代）
- HP：1
- 机制：HP 只有 1 点。**"直接应对"永远造成 0 伤害**（你不能打孩子）。需要**感知 ≥ 40** 后，"说点什么"可以造成 1 点伤害（一击结束）。感知不足时，"说点什么"也无效（"你不懂我！"）
- 失败/绕过：5 回合后孩子摔门走人，获得 debuff「代沟」(与该区 NPC 好感度获取效率-50%，持续到本代结束)
- 台词风格：青春期少年语气，每句话都是"你不懂"
- 范例台词："你不懂。你从来就不懂。算了不说了。说了你也不懂。（三秒后）你怎么不问我怎么了？你看你根本不关心我。"
- 设计意图：你不能用力量解决，只能用理解

---

**天敌 11：扎根积分系统**

- 类型：限时爆发型
- 出现阶段：终章（66岁+）
- 出现条件：结局线触发（11 区好感度 ≥ 60 后）
- HP：100,000
- 机制：10 回合限时。每回合全属性-1%（官僚磨损）。需要在 10 回合内打出 100,000 伤害
- 破解：需要黑色稀有度异常物品展开至层级 9（×30 倍率），才有可能在 10 回合内打出 10 万伤害
- 失败：积分不够 → 未获得地头认证 → 本代结束，继承开始。下一代可以再试
- 台词风格：政务窗口语气，永远在转圈
- 范例台词："你还差1,247分。本回合获得3分。按此速度，约需416回合。你有10回合。请问还有什么可以帮到您的？取号请按1。"
- 设计意图：最终的墙。有些系统不是为了被打败而设计的，但你可以尝试

**天敌 12：医院挂号系统**

- 类型：隐藏条件型 + 无限生存
- 出现阶段：老年期（66岁+）
- 出现条件：健康事件触发
- HP：???（隐藏）
- 机制：血条不可见，且无法造成伤害。每回合在不同科室间被转来转去（随机 debuff）。需要持有特定道&#x5177;**「医保卡」**&#x540E;血条显现（HP: 50），正常战斗可击败
- 失败/绕过：没有医保卡 → 10 回合后被"建议转院" = 自动结束，但获得 debuff「延误治疗」(生命上限-20%，持续到本代结束)
- 台词风格：分诊台护士语气，永远在转科室
- 范例台词："你这个情况不归我们科。你去三楼看看。三楼说去五楼。五楼说你这个得去一楼重新挂号。你刚才在一楼对吧？对。那就对了。重新排队吧。"
- 设计意图：有些系统不让你看见目标，你得先有"钥匙"

### 21.6 天敌与异常展开系统的关系

天敌并非全部需要异常展开——有些靠属性门槛，有些靠策略，有些靠特定道具。

**需要异常展开的天敌：**

- 996加班 → 需要红色物品层级 7+ 的爆发力
- 扎根积分系统 → 需要黑色物品层级 9 的极限爆发
- 税务稽查 → 蓝色物品层级 4+ 可以显著帮助（但非必须）

**不需要异常展开的天敌：**

- 校园霸凌 → 需要韧性属性
- 期末考试 → 需要专注状态
- 相亲对象 → 需要沟通策略
- 论文查重 → 需要行动多样性
- 早高峰 → 需要闪避属性
- 房东 → 需要金钱
- 中年危机 → 需要异常数量（但不是展开）
- 孩子叛逆期 → 需要感知属性
- 医院挂号 → 需要特定道具

设计意图：**异常展开是工具之一，不是唯一答案**。这确保不同 build 的角色都有天敌可打，也有天敌要躲。

### 21.7 天敌与结局的关系

击败天敌不是必须的——玩家可以绕过。但：

- 扎根积分系统是结局触发条件的一部分（11 区好感度 ≥ 60 后才能挑战）
- 其他天敌的击败会提供该区域的好感度加成和叙事碎片
- 绕过天敌通常有 debuff 代价

设计意图：**天敌是"做客"体验的制度化具象**。你不是在打怪物，你是在打那些让你永远当"客人"的系统。但有些系统你确实打不过——那也没关系，你可以绕过去，带着伤疤继续生活。

## 二十二、数值架构（Layer 1 定稿）

### 22.1 三层属性体系

属性分为三层，自下而上计算：

**Tier 1 — 身体组件（原始数值）**  
6 个组件，每个有效能(efficacy) / 稳定(stability) / 成长(growth) 三项数值。

三项数值的分工：

- **效能** → 喂给基础属性（主力）。决定角色"有多强"。
- **稳定** → 不喂属性，影响"可靠性"和"异常可控性"。稳定高 = 输出一致（±5%）、异常可控；稳定低 = 输出波动大（±30%）、异常可能自行爆发。决定角色"有多稳"。
- **成长** → 不喂属性，影响效能提升速率。成长高的组件学技能更快。决定角色"有多快变强"。

**Tier 2 — 基础属性 + 桥接值**

| 基础属性           | 来源组件    | 公式                                |
| -------------- | ------- | --------------------------------- |
| 生命(maxHp)      | 躯干      | `躯干效能 × 5 + 30`                   |
| 精力(maxStamina) | 躯干 + 大脑 | `(躯干效能 + 大脑效能) + 10`              |
| 行动力            | 左腿 + 右腿 | `(左腿效能 + 右腿效能) / 2`（差值惩罚后，见 23.1） |
| 感知             | 大脑      | `大脑效能 + 5`                        |
| 机缘             | 大脑      | `大脑效能 × 0.5`                      |
| 韧性             | 躯干      | `躯干效能 × 0.5 + 5`                  |
| 力量（桥接值）        | 左手 + 右手 | `(右手效能 + 左手效能) / 2`（差值惩罚后）        |

力量不是传统基础属性，是双手效能的中间计算结果，专门给战斗衍生属性用。力量对玩家可见。



**Tier 3 — 衍生属性（战斗实际读取的数值）**

| 衍生属性  | 来源       | 公式                        | 物品可否直注   |
| ----- | -------- | ------------------------- | -------- |
| 攻击力   | 力量       | `力量 × 2 + 装备攻击力`          | 是        |
| 暴击率   | 力量       | `5% + 力量 × 0.5%`          | 是（肾上腺素等） |
| 暴击伤害  | 力量       | `1.5× + 力量 × 0.01`        | 是        |
| 闪避率   | 行动力 + 感知 | `(行动力 + 感知) × 0.3%`       | 是        |
| 命中率   | 感知       | `80% + 感知 × 0.5%`（上限 95%） | 是        |
| 减伤率   | 韧性       | `韧性 × 0.5%`（上限 40%）       | 是        |
| 异常触发率 | 机缘       | `10% + 机缘 × 0.5%`         | 是        |

异常触发率影响两件事：异常物品每回合展开上升概率、异常物品获取概率。机缘高的角色 = 高风险高回报，物品展开更快但副作用也来得更快。

暴击的 thematic 定位：暴击不是"力气大打得疼"，而是"异常在那一瞬间失控爆发"。暴击触发时有异常风格文案。

### 22.2 物品注入的两个入口

物品可以在两个不同层级注入属性：

- **入口 A：注入 Tier 2（改基础属性）** — 如「躯干护甲」→ +生命值。改变角色基本面，所有依赖属性跟着变。这是"治本"型物品。
- **入口 B：注入 Tier 3（改衍生属性）** — 如「肾上腺素」→ +暴击率。不碰基础属性，直接给战斗结果加成。这是"治标"型物品，效果直接但可能有时限。

### 22.3 区域与属性的关系

区域不碰基础属性链，只影响效果层：

- 组件效能从金涌走到野坪不会变——你这个人没变
- 但道具/技能/异常的效果在 不同区域有修正（如「室内打伞」在野坪效果增强）
- 区域异常类型影响：异常展开速度、道具效果修正、事件触发池
- 计算链保持干净：`组件效能 → 基础属性 → 衍生属性`，区域只在最后一步作为效果修正系数介入

### 22.4 数值展示方式

混合展示：

- **基础属性**：显示精确数字（"感知: 17"）
- **衍生属性**：显示百分比（"暴击率: 13.5%"）
- **异常/区域修正**：显示为文字描述，不显示数字（"你的右手在野坪格外不安分"）
- **稳定值影响**：用描述提示（"稳定：低（表现忽高忽低）"），不显示方差范围

### 22.5 年龄-属性曲线（非线性）

属性随年龄的变化不是线性成长，而是 S 型曲线 + 老年断崖：

- **婴儿期（0-5岁）**：所有属性压到极低值，HP 固定 10。童年是"躲避求生"阶段。
- **成长期（6-35岁）**：S 型曲线加速成长，青年期末接近峰值。
- **巅峰期（36-65岁）**：属性天花板，数值最高点。挑战天敌的黄金窗口。（壮年期大幅延长）
- **衰退期（66-80岁）**：缓慢下滑。
- **断崖期（80岁+）**：超过衰退阈值后，所有属性同步按比例下降。事件/道具可造成属性波动——不是单调下降，有时候一件好道具能让你 95 岁还保持壮年七成战力。

三层死亡线：

- **90 岁**：常规终老。大多数角色在这个年龄自然死亡。
- **120 岁**：道具延寿极限。通过强力道具可以延寿到此，但越来越难维持。
- **150 岁**：强制老死。绝对硬上限，无论道具、属性、事件如何，到 150 岁立刻死亡。

更新后的人生阶段：

| 阶段 | 年龄            | 特征        | 游戏时间    |
| -- | ------------- | --------- | ------- |
| 童年 | 0-12          | 10HP，躲避求生 | ~8 min  |
| 少年 | 13-18         | 快速成长      | ~10 min |
| 青年 | 19-35         | 接近峰值      | ~25 min |
| 壮年 | 36-65         | 巅峰期（大幅延长） | ~40 min |
| 中年 | 66-80         | 缓慢衰退      | ~20 min |
| 老年 | 81-90/120/150 | 断崖+道具波动   | ~17 min |

## 二十三、身体组件系统（Layer 1 定稿）

### 23.1 组件间联动

配对组件（左右腿、左右手）采用 **均值 + 差值惩罚** 机制：

`配对结果 = (左 + 右) / 2 - max(0, |左 - 右| - 5) × 0.3`

- 差值 5 以内不惩罚（正常惯用手差异）
- 差值超过 5 开始扣，奖励均衡发展
- 差值极大时本身可成为异常触发条件（"你的右手比左手强太多，右手开始看不起左手"）

### 23.2 组件受损与医疗系统

**组件受伤**：

- 战斗中组件可被"打伤"——临时效能下降 30-50%
- 受伤文案走搞笑风格："你的左腿被踢了一脚。它在闹情绪。"
- 轻伤（-30% 以下）3 天自动恢复
- 重伤（-50%）需要就医，不自动恢复

**看病难**：  
看病本身是一个设计点，与天敌「医院挂号」系统联动：

| 要素   | 设计                                           |
| ---- | -------------------------------------------- |
| 公共医院 | 便宜（50 元），但需排队——触发「医院挂号」天敌前置条件，排队期间伤势可能恶化     |
| 私人诊所 | 贵（500 元），即时治疗，无排队风险                          |
| 医保卡  | 持卡：公共医院免费、私人诊所半价。鲲生初始持有，过江客需通过事件/任务获取      |
| 庸医事件 | 低概率遇到庸医，治好了伤但随机给一个组件加异常——"你的左腿不疼了，但它现在会自己走了" |

完整链条：受伤 → 要看病 → 看病难（挂号天敌）→ 没医保卡 → 看不起 → 带伤战斗 → 更容易受伤 → 恶性循环。

### 23.3 装备与组件的交互

装备对组件的影响分三个层面：

| 层面     | 效果            | 例子                 |
| ------ | ------------- | ------------------ |
| 数值加成   | 直接加效能         | 烧鹅刀 → 右手效能 +5      |
| 衍生属性注入 | 直接加衍生属性       | 防弹公文包 → 减伤率 +12%   |
| 异常展开   | 装备本身是异常物品，可展开 | 烧鹅刀(蓝色) → 可展开至层级 4 |

不做"装备改变组件行为模式"——行为改变由异常展开系统覆盖。

### 23.4 组件数值范围与初始值

| 参数       | 值                   |
| -------- | ------------------- |
| 基础初始效能   | 10                  |
| 基础初始稳定   | 10                  |
| 基础初始成长   | 1.0                 |
| 出身修正幅度   | +2 ~ +5（修正 1-2 个组件） |
| 效能软上限    | 50（正常成长 + 继承可达）     |
| 效能硬上限    | 80（几乎不可能，需多代积累）     |
| 一代自然成长范围 | 10 → 25~35          |
| 一代专注成长范围 | 10 → 40~50          |

### 23.5 投胎签系统

每次新角色出生时（包括继承的新一代），完全随机抽取身份标签：

| 标签   | 概率   | 机制影响                                                                |
| ---- | ---- | ------------------------------------------------------------------- |
| 鲲生  | ~40% | 免战「扎根积分」天敌、初始持有医保卡、机缘 +3、韧性 -2（没被社会毒打过）、各区好感度获取速率 -20%（自认地头，不主动融入） |
| 过江客 | ~60% | 必须面对「扎根积分」天敌、无医保卡、韧性 +3（被毒打过）、机缘 -1、好感度获取速率 +10%（有动力融入）             |

设计张力：

- 鲲生跳过最终 Boss，但"做客→成为地头"对他们更难——好感度难刷
- 过江客要打扎根 Boss，但好感度好刷——殊途同归，难度不同
- 第一代大概率过江客，第二代有概率变鲲生——血脉从"外来"到"本地"的演变在机制上自然发生

## 二十四、成长与寿命系统（Layer 1 定稿）

### 24.1 成长驱动方式

混合三层驱动：

- **保底成长（时间驱动）**：每个生命阶段过渡时，所有组件 +1 效能。活着就会变强一点。
- **使用加速（使用计数）**：战斗中使用某组件相关行动（右手攻击、双腿闪避、大脑感知等），该组件获得额外经验。每个组件每天最多积累 3 点使用经验，防刷。
- **事件爆发（事件驱动）**：完成关键事件/击败天敌时，获得 3-5 个"成长点"，可自由分配到任意组件。

### 24.2 角色等级

**无角色等级，纯组件驱动。**

角色强弱完全由 6 个组件的效能决定。没有经验值 grind，没有笼统的等级数字。继承时传的是组件天赋（某组件成长 +0.5），不是等级。

### 24.3 成长节奏

| 阶段        | 自然成长（保底） | 专注成长（使用+事件） | 组件效能范围 |
| --------- | -------- | ----------- | ------ |
| 童年结束(12岁) | +2       | +3~5        | 15-17  |
| 少年结束(18岁) | +2       | +4~6        | 19-25  |
| 青年结束(35岁) | +3       | +6~10       | 25-38  |
| 壮年结束(65岁) | +2       | +4~8        | 28-45  |
| 老年(80岁+)  | -1~-3    | 事件可逆        | 下降中    |

一代角色不刻意培养，组件效能约 25-30；专注培养 1-2 个组件可到 40-45；继承天赋加成再多 5-8。6 个组件全练满（50+）几乎不可能——迫使玩家做取舍。

### 24.4 成长反馈

不弹窗，阶段总结时统一汇报。

每个生命阶段过渡时弹出"阶段总结"面板，列出该阶段所有组件变化。文案走搞笑风格：

> **少年期总结（13-18岁）**
>
> 右手效能 15 → 22 — "你终于学会了用拳头解决说话解决不了的问题。"
>
> 大脑效能 18 → 20 — "大脑微微变大。看不出区别但确实大了。"
>
> 左腿效能 12 → 12 — "左腿这五年什么都没干。它很享受。"
>
> 新获得异常：右手·停不住手 — "你的右手开始有自己的想法了。"

## 二十五、技能系统（Layer 1 定稿）

### 25.1 技能结构

```
{
  id, name, description,
  type: "passive" | "active",
  source: "origin" | "anomaly" | "event" | "npc" | "inheritance",
  boundComponent: 组件类型,
  triggerAction: 战斗行动类型（active 技能）,
  baseEffect: { type, value },
  scalingStat: "efficacy",
  scalingCoeff: 系数,
  condition: 触发条件,
  conflicts: [冲突技能 id 列表],
  placementEffects: { 组件类型 → 效果 }  // 多组件放置
}
```

技能效果 = 基础效果 + 组件效能 × 缩放系数。技能本身没有等级，强弱由绑定组件的效能决定。

### 25.2 技能获取途径

| 途径     | 数量预期  | 条件                  |
| ------ | ----- | ------------------- |
| 出身初始   | 1 个   | 角色创建时自动获得           |
| 异常伴生   | 1-3 个 | 获得异常时有概率伴生相关技能      |
| 事件奖励   | 2-4 个 | 完成特定事件后获得，部分事件给技能选择 |
| NPC 传授 | 1-2 个 | 好感度达「熟络」以上，NPC 主动教你 |
| 自悟     | 0-1 个 | 某类行动使用超过 30 次概率触发   |
| 继承配方   | 0-3 个 | 上一代传下配方，满足简化条件后解锁   |

一代角色约获得 5-11 个技能。

### 25.3 技能升级

不做独立技能升级系统。技能效果随组件效能自动增强。

保留概念：**熟练度解锁变体**——同一技能使用 20 次后解锁一个变体效果，不是数值增强而是功能拓展。

> 例子：「室内打伞」使用 20 次后解锁变体「室外收伞」——室外战斗时也有 5% 闪避，因为你的伞不知道该开还是该收，它选择永远开着。

### 25.4 技能与组件的绑定

所有技能都绑定组件，没有"独立"技能：

- 出身技能 → 绑定出身强化的组件
- 异常伴生技能 → 绑定触发异常的组件
- 事件/NPC/自悟技能 → 绑定与技能主题最相关的组件
- 继承配方技能 → 绑定与上一代相同的组件

绑定组件受伤 → 绑定技能效果下降。绑定组件被异常展开 → 绑定技能可能被强化或扭曲。

### 25.5 技能槽位、互克与多组件放置

**槽位**：每个组件 5 个技能槽，6 组件共 30 槽。槽位可以装任意技能，但装在非绑定组件上效果减半。

**多组件放置**：同一个技能装在不同组件上，效果完全不同——不是打折的同一效果，而是不同的技能表现。

以「论语」为例：

| 放置组件   | 触发方式   | 效果                  | 叙事                         |
| ------ | ------ | ------------------- | -------------------------- |
| 大脑（绑定） | "说点什么" | 敌人 -30% 攻击力 2 回合    | "子曰：打架是不好的。敌人陷入了自我反省。"     |
| 右手     | "直接应对" | +50% 伤害但 -10% 自身 HP | "以德服人。服得很用力。你也疼。"          |
| 躯干     | 被动     | +20% 韧性，不能逃跑        | "君子不立危墙之下。但君子也不跑。"         |
| 左腿     | "跑"    | 逃跑时留下一句论语，敌人愣 1 回合  | "三十六计，走为上策。子曰这话不是我说的但先走了。" |

**互克系统**：某些技能对存在冲突关系，同时装备时双双失效并触发搞笑 debuff。

| 技能 A | 技能 B  | 冲突效果                      | 叙事                                    |
| ---- | ----- | ------------------------- | ------------------------------------- |
| 论语   | 春秋    | 左右脑互搏，双双失效，每回合 5% 概率自己打自己 | "左脑在背论语，右脑在背春秋。它们吵起来了。你挨了一拳。不知道是谁打的。" |
| 室内打伞 | 假装没看见 | 存在主义悖论，双双失效，感知 -5         | "你撑着伞假装没看见任何东西。但伞让你很显眼。宇宙困惑了。"        |
| 调试   | 火候    | 理性与感性冲突，双双失效，暴击率归零        | "你的右手在调参数，你的左手在凭感觉。它们打架。你什么都做不好。"     |

一个技能本质上是 4-6 个不同的技能变体（取决于放哪里）。互克系统确保你不能什么都带——你必须选择你的"道"。

### 25.6 技能与战斗行动的对接

技能不成为第 6 个战斗选项，而是修改现有 5 个行动：

| 技能类型     | 对接方式          | 例子                            |
| -------- | ------------- | ----------------------------- |
| 被动技能     | 自动生效，不占行动     | 假装没看见 → 15% 概率自动跳过遭遇          |
| "说点什么"技能 | 选"说点什么"后弹出子菜单 | 调试 → "你的攻击模式有个 bug"，敌人下回合行动暴露 |
| "直接应对"变体 | 给"直接应对"增加特殊效果 | 火候 → 直接应对时附带火焰异常              |
| "用东西"增强  | 修改道具使用效果      | 讲价 → 买东西打 8 折                 |
| "跑"技能    | 修改逃跑行为        | 绕路癖 → 逃跑时绕路但捡到东西              |

### 25.7 技能配方

配方 = 下一代快速重学上一代技能的条件。

- 学会技能时同时获得该技能的"配方"
- 角色死亡时配方作为"已解锁知识"传入继承
- 下一代满足配方的简化条件后可直接学会，不需要重新触发原事件
- 配方可叠加——同一技能传了 3 代，条件简化到"去那个区走一圈就行"
- 配方只传知识，不传熟练度——变体效果每代重新刷

> 例子：上一代通过"在野坪淋雨 3 天"学会了「室内打伞」，配方传入下一代。下一代只需要"在野坪淋雨 1 次"就能学会——上一代的经验让你少淋了 2 天雨。

## 二十六、异常系统（Layer 2 定稿）

### 26.1 异常触发规则

混合三层触发：

- **事件触发（主）**：遭遇特定事件后获得（"你在野坪淋了一场雨，右手开始不听话了"）
- **阈值触发（辅）**：组件效能达到某个值时自动获得（"你的右手太强了，它开始有自己的想法"）
- **随机触发（调剂）**：每天极小概率随机获得（"今天什么都没发生但你的左腿突然会跳探戈了"）

一代角色约获得 **10 个异常**（终生累计）。同时最多 6 个活跃（6 组件各 1 个）。

异常会流动：
- 新异常可覆盖旧异常
- 异常可被治愈（医疗/事件/继承净化），腾出槽位
- 某些异常有自然周期（童年获得的到少年自动消失，"你长大了，左腿不跳探戈了"）

### 26.2 异常叠加与联动

- 一个组件最多 1 个异常
- 不同组件异常之间会联动——右腿"绕路癖"+右手"停不住手"同时存在时，逃跑会绕路但手停不住地捡东西，等于"逃跑时必捡到一个随机道具"
- 联动效果在获得第二个异常时自动生成提示："你的右腿想绕路，你的右手想捡东西。它们达成了协议。"

### 26.3 异常强化与抑制

| 操作 | 方式 | 效果 |
|------|------|------|
| 强化 | 花成长点投入异常组件 | 异常效果增强，但副作用也增强 |
| 抑制 | 装备特定道具 | 异常效果降低，副作用也降低 |
| 根除 | 看病（庸医/特殊事件） | 异常消失，但可能获得新异常 |

强化和抑制都是双向调整——不能只要好处不要坏处。

### 26.4 稳定与异常的张力

稳定值影响异常自行爆发概率：

| 稳定值 | 自行爆发概率 | 表现 |
|--------|------------|------|
| 10 | 20% | "你正在跟 NPC 说话，右手突然停不住地扇了自己一巴掌" |
| 30 | 5% | 偶尔失控 |
| 50 | 0% | 完全可控 |

高稳定 = 异常只在你主动使用时触发。低稳定 = 异常有概率在你不想的时候自行爆发。

### 26.5 异常与天敌掉落

Boss 战（天敌）除了掉落装备，还会掉落异常。击败天敌后获得的天敌专属异常往往是强力的、不可通过其他途径获得的。

## 二十七、装备系统（Layer 2 定稿）

### 27.1 装备获取

| 来源 | 说明 |
|------|------|
| 商店购买 | 各区有不同商店，卖不同区域的日常物品 |
| 事件奖励 | 完成事件给装备 |
| 敌人掉落 | 击败天敌/普通敌人概率掉落，天敌必掉装备+异常 |
| 地图拾取 | POI 互动时发现 |
| 制作合成 | 用配方+材料合成（需已知配方） |
| 继承获得 | 上一代传下的传承物品 |

### 27.2 装备耐久与共鸣碎片

每件装备有耐久值（10-50 视稀有度）。每次战斗使用消耗 1 点，异常展开消耗 2 点。

**修理不用金钱，用「共鸣碎片」**：

| 要素 | 设计 |
|------|------|
| 获取 | 击败天敌、异常事件、特殊区域活动（如野坪冥想、潮湾祭典） |
| 用途 | 修复异常装备耐久、抑制异常自行爆发、稳定低稳定组件 |
| 稀缺性 | 一代角色约获得 20-30 个，修理一件金色装备需 5 个 |

**装备耐久归零时的命运**：

| 稀有度 | 耐久归零后 |
|--------|----------|
| 白色 | 直接消失 |
| 蓝色 | 直接消失 |
| 紫色 | 30% 概率转生为隐藏异常（变红色，效果完全改变） |
| 金色 | 50% 概率转生 |
| 红色 | 100% 转生，但转生后属性随机化 |
| 黑色 | 不会归零（耐久无限），但每回合使用有 1% 概率反噬——"它不需要你修。它修你。" |

转生 = 装备消失，异常效果以新形态附着在组件上，变成红色隐藏异常。创造赌博式决策：修还是赌转生？

### 27.3 装备库存

- 装备有独立库存，不占道具背包格子
- 上限 30 件
- 可丢弃/出售

## 二十八、道具系统（Layer 2 定稿）

### 28.1 背包系统

| 要素 | 设计 |
|------|------|
| 容量 | 20 格（可扩容到 30 通过特定道具/事件） |
| 叠加 | 消耗品可叠加（上限 99），非消耗品不叠加 |

### 28.2 道具使用场景

- **探索中使用**：地图上使用，效果持续或即时

- **同一道具不同场景效果不同**：便利店收据在战斗中 = 扔出去糊脸（5% 混乱），在对话中 = 证明你昨天确实买了东西

### 28.3 关键道具

- 任务道具独立存放，不占背包格子
- 关键道具有专属标记，不能丢弃/出售
- 医保卡是典型关键道具

## 二十九、战斗系统（Layer 2 定稿）

### 29.1 伤害公式

```
基础伤害 = 攻击力 × 攻击动作修正
暴击判定 = 暴击率 roll → 暴击则 × 暴击伤害
命中判定 = 命中率 vs 目标闪避率
最终伤害 = 基础伤害 × (1 - 目标减伤率) × 异常展开倍率
```

攻击动作修正：直接应对 ×1.0，"说点什么"攻击变体 ×0.7（但附带异常效果），"用东西"攻击性道具 ×1.5

### 29.2 回合顺序

按战斗类型计算先手：
- 学习类战斗（考试/辩论/调试）：精力高的先手
- 运动类战斗（追逐/体育/通勤）：行动力高的先手
- 普通战斗：行动力高的先手

### 29.3 小队系统

| 要素 | 设计 |
|------|------|
| 队伍规模 | 1-3 人（主角 + 最多 2 队友） |
| 队友来源 | NPC 好感度达「熟络」后可邀请入队 |
| 队友数值 | 有独立组件和属性，但简化（只显示 HP/主要属性） |
| 队友控制 | AI 控制，玩家可设战术倾向（激进/保守/支援） |
| 队友成长 | 跟主角一起获得保底成长，不获得使用加速 |
| 队友异常 | 队友可以有异常，但数量少（0-1 个） |

### 29.4 胜负条件

| 结果 | 后果 |
|------|------|
| 胜利 | 获得成长点、道具/装备掉落、金钱、好感度变化 |
| 失败（HP归零） | 不直接死亡 → 进入"倒地"状态，3 回合内队友可救 |
| 全队倒地 | 战斗失败 → 损失 30% 金钱 + 随机一件装备损坏 + 一个组件受伤 |
| 天敌失败 | 按天敌机制处理（迟到/emo/被抽税等），不死亡 |
| 致死战斗失败 | 角色死亡。真死。直接进入继承。 |

普通战斗失败不致死——只有致死战斗和年龄到限才会致死。

### 29.5 致死战斗

极少数特殊战斗，输了 = 角色死亡。每代 1-2 场，出现在关键叙事节点，可选。

战斗前系统提示："这场战斗输了会死。不是倒地。是死。字面意义上的死。"

**友情小队**：
- 3 个敌人，互相加 buff，越打越强
- 台词："因为友情！""因为羁绊！""因为我们相信彼此！"
- 机制：每回合一个敌人给另一个加 buff，3 回合后全员强化到几乎无敌
- 破解：在 3 回合内击杀一个，buff 链断裂，其余崩溃
- 输了死。赢了获得共鸣碎片×10 和一个红色异常装备
- 系统：你才是反派。他们是主角。主角总是赢的。除非你比主角更像主角。

**中年社畜的终极一战**：
- 单人 Boss，HP 不高但每回合回满
- 台词："我不能死。我有房贷。我有孩子。我有——"
- 机制：必须用"说点什么"打断他的自我说服，3 次后他崩溃
- 输了死。赢了获得大量金钱和一个金色异常装备
- 系统：他的求生意志比你强。因为他的房贷比你狠。

### 29.6 战斗触发

| 类型 | 触发方式 |
|------|---------|
| 可见遭遇 | 地图上可见敌人，接触触发（可绕开） |
| 随机遭遇 | 某些区域行走时概率触发（可被道具降低） |
| 事件遭遇 | 事件选项导致战斗（不可回避） |
| 天敌遭遇 | 特定条件触发（按天敌设计） |

### 29.7 "装作没事"的概率机制

```
消失概率 = 10% + 稳定 × 0.3% + 区域法则修正
```

- 稳定越高，装得越像没事 → 概率越高
- 某些区域法则让"装作没事"更容易成功（野坪：边界渗透，"也许它真的不存在"）
- 失败：敌人正常攻击，你下回合 -10% 闪避（"你装得太明显了"）
- 成功：敌人消失，无掉落无经验（"它走了。也可能它从来没来过。你选择相信后者。"）

## 三十、探索与地图系统（Layer 3 定稿）

### 30.1 地图规模

每个区包含 **4-5 个分区地图**，每张 30×20 格（16×16 像素 tile）。11 区 × 4-5 分区 = 约 50 张地图。

### 30.2 移动方式

| 方式 | 条件 | 效果 |
|------|------|------|
| 步行 | 默认 | 正常速度，可遇敌、可互动 POI |

| 捷径 | 发现后解锁 | 区内快速跳转到已发现 POI，不消耗阶段 |

### 30.3 POI 系统

每个分区 5-8 个 POI，走到附近自动发现。POI 类型：商店、NPC 据点、事件点、休息点、特殊点（区法则互动）、地标建筑、通用建筑。

地标与通用建筑示例（金涌）：证券交易所、政心大厅、莲坪公园、格子广场、关口、咕咕广场、写字楼大堂、便利店、咖啡店、快餐店、修手机铺、健身房、图书馆。

### 30.4 时间系统

| 要素 | 规则 |
|------|------|
| 1 年 | 7 天 |
| 1 天 | 2 阶段（早/晚） |
| 1 阶段 | 1 个动作 |
| 每年可控阶段 | 14 个（成年），童年递减 |

| 年龄段 | 每年可控阶段 | 说明 |
|--------|------------|------|
| 0-5 岁 | 0（自动叙事） | 全自动，"你在蹒跚学步。左腿效能+1。" |
| 6-12 岁 | 4/年 | 童年可控但有限 |
| 13-18 岁 | 10/年 | 少年期大部分可控 |
| 19+ 岁 | 14/年 | 成年完全可控 |

一生约 1000 个可控动作。可选动作：探索 / 工作 / 社交 / 训练 / 合成 / 休息 / 购物 / 旅行 / 什么都不做（小幅恢复精力）。

### 30.5 地图 UI

- 不显示完整地图（探索式发现，走过才点亮）
- 小地图只显示当前分区已探索区域 + 已发现 POI
- 区间连接在到达边缘时显示"前往 XX 区"提示
- HUD 显示当前位置、日期、阶段（早/晚）

#### 童年（5 个）

**1. 楼梯口的六年级**（1 滴血，但你不敢打）
- 你看到的：比你高两头的人，每天在楼梯口等你。他什么武器都没有。
- 那一刻：他的影子罩住你。你手里的零花钱已经不属于你了。你恨自己腿软。

**2. 满篇红叉的卷子**（限时：家长签字倒计时）
- 你看到的：一张纸。上面全是红叉。分数栏写着"59"。
- 那一刻：你妈签字的那支笔，比任何 boss 的武器都重。你想把卷子藏起来，但你妈已经收到老师微讯了。

**3. 陈浩然**（属性门槛：感知 ≥ 25 才能看到他的弱点）
- 你看到的：每次考试比你多一分的人。他妈妈跟你妈妈同一个家长群。99 条未读消息。
- 那一刻：他冲你笑了一下。你恨那个笑。你恨自己恨那个笑。

**4. 穿西装的小孩**（资源消耗：每回合抽 1 精力）
- 你看到的：一个比你还小的小孩，穿着不合身的西装，递给你一张传单。"您的孩子需要全面发展。"
- 那一刻：他已经知道你家长的电话号码了。下节课免费试听。你不想去，但你妈想去。

**5. 打针的队伍**（无限生存：撑 5 轮）
- 你看到的：一条看不到尽头的队伍。前面的孩子在哭。后面的孩子也在哭。消毒水味。
- 那一刻：你排了三个小时。前面还有八十个人。护士面无表情地叫号。

#### 少年（5 个）

**6. 查重率 99.8%**（每回合增加重复率，降到 15% 以下才算赢）
- 你看到的：屏幕上红色的字比黑色的多。"您的论文与以下 47 个来源高度相似。"
- 那一刻：你写了一个通宵。它说你是抄的。你确实是参考了的，但你没抄。

**7. 挤不上去的 4 号线**（无限血条，只能闪避）
- 你看到的：车门关了。又关了。你的脸贴在玻璃上。里面的人也在看你。
- 那一刻：第三班车了。你还在月台上。你已经迟到了。迟到三次扣绩效。

**8. 倒计时**（隐藏条件：连续训练 3 次显血；限时 5 回合）
- 你看到的：黑板上写着"距高考还有 3 天"。数字每天在变少。你的手在抖。
- 那一刻：你会的题突然全忘了。不会的题格外清晰。每一秒都像一节课。

**9. 手电筒的光**（镜像：5 种行动各用 1 次）
- 你看到的：操场上一个手电筒。光柱扫过来。你旁边的人是你喜欢的人。
- 那一刻："你们两个，哪个班的？"你想解释。但你解释什么都是错的。

**10. 没有窗户的房间**（资源消耗：每回合降感知，装备没收）
- 你看到的：白色墙壁。没有手机。没有电脑。门从外面锁着。
- 那一刻："电击治疗是一种关爱。"你不确定这是不是你妈说的。你不确定这是不是你妈。

#### 青年（6 个）

**11. 对面坐着的人**（限时：3 回合找到共同话题，否则好感归零）
- 你看到的：一个你妈同事介绍的、你从没见过的人。TA 在看手机。你也在看手机。
- 那一刻：沉默。你们没有任何共同话题。但你妈明天会问。"怎么样？"

- 你看到的：一张桌子。对面的人拿着你的简历，翻到第二页，停住了。
- 那一刻："你有什么要问我的吗？"你脑子空了。你准备了一晚上的问题全忘了。

**13. 押一付三**（属性门槛：机缘 ≥ 20）
- 你看到的：一个比你卧室还小的房间。中介说"这是性价比最高的"。墙上有一道裂缝。

**14. 账单日**（资源消耗：利息滚利，限时还清）
- 你看到的：一条短信。"您本期应还款：¥12,847.00。最低还款：¥1,284.70。"
- 那一刻：你只还了最低还款。下个月它变成了一万三。你知道这是错的，但你没有别的选择。

**15. 讯圈里永远在旅游的那个人**（无限生存：撑 7 轮不看手机）
- 你看到的：TA 在冰岛。TA 在北海道。TA 在吃米其林三星。你在吃外卖。
- 那一刻：你的大拇指停在屏幕上。你已经刷了四十分钟。你点了个赞。你又恨自己点了个赞。

**16. 打卡机**（无限生存：闪避生存）
- 你看到的：9:01。红色的字。你的指纹按上去，机器说"迟到"。
- 那一刻：全勤奖没了。今天的早餐也白买了。你跑了一路，还是差了一分钟。

#### 壮年（7 个）

**17. 税务局的挂号信**（限时：3 日内自证清白）

**21. 面试你孩子的人**（隐藏条件：说点什么 3 次，不重复话题）
- 你看到的：一个老师问你的孩子："你最喜欢什么书？"你的孩子沉默了。

**24. 后视镜里的自己**（每回合随机降一项属性，需要找到"活着的证据"）

**25. 关上门的房间**（隐藏条件：找到 3 次正确时机敲门）
- 你看到的：你孩子的房门关着。里面有音乐。你敲门。没人应。
- 那一刻：你昨天还在教 TA 骑自行车。今天 TA 不愿意跟你吃饭了。你端着水果在门口站了五分钟。

**26. 排号单上的数字**（无限生存：撑 10 轮）
- 你看到的：一张纸。"您前面还有 347 人。"你妈问你什么时候能住进去。
- 那一刻：她说"没事，家里也行。"你知道她在骗你。她也知道你知道。

**27. 35**（属性门槛：力量 ≥ 30 或大脑 ≥ 35）
- 你看到的：招聘网站的筛选条件。"35 岁以下。"你已经 36 了。
- 那一刻：你删掉了简历里的出生年份。但 HR 看得出来。他们都看得出来。

**28. 温度计**（资源消耗：每回合随机组件 -10%）
- 你看到的：你的身体不再是你认识的那个了。一阵热。一阵冷。失眠。凌晨三点醒。
- 那一刻：你从没想过，体温也是一种敌人。你盖了被子。又踢了被子。又盖了。

#### 老年（6 个）

**29. 扎根窗口的玻璃后面**（无限血条，每回合获 3 分，需凑满 1247 分）
- 你看到的：扎根窗口。TA 面无表情。"你还差 1247 分。本回合获得 3 分。"
- 那一刻：你在鲲城住了 40 年。你的孩子生在鲲城。你还是不算鲲城人。

**30. 7:00 的挂号窗口**（限时：号挂完就结束）
- 你看到的：你 5 点来的。前面已经排了 60 个人。专家号只剩 2 个。
- 那一刻：你的膝盖在疼。你不确定排到的时候号还在不在。你不确定明年还在不在。

**31. 她的音响**（镜像：斗舞）
- 你看到的：一个比你年轻 10 岁的阿姨。她的音响比你的大。她的人比你的多。
- 那一刻："这个位置是我先来的。"你也是这么说的。但她先放大音响的。

**32. 计算器**（限时爆发：10 回合 5 万伤害）
- 你看到的：一个计算器。屏幕上的数字在变少。你交了 35 年社保。它告诉你每月领 3200。
- 那一刻：你的房贷还有 8 年。你的退休金不够还。你关掉计算器，又打开了。

**33. 满了的班级**（隐藏条件：需持有 3+ 异常）
- 你看到的："书法班已满。""国画班已满。""太极拳班已满。"
- 那一刻：你排了三个队的号。都是"已满"。你退休了，连学东西都要排队。

**34. 遗嘱**（资源消耗：每回合抽钱，赢了全拿回）
- 你看到的：你的孩子们坐在你床边。他们在等你说话。他们的眼睛在看你的抽屉。
- 那一刻：你想说"别说这些。"但你知道迟早要说。你开始分配。没人满意。

### 32.6 天敌分布按时代变化

部分天敌受鲲城发展时间线影响：
- 第 1-2 代没有 996 加班（还没有互联网行业）
- 第 5 代后才有扎根积分系统（政策变化）
- 第 7 代后广场舞地盘争夺更激烈（老年人口增加）

## 三十三、事件与任务系统（Layer 3 定稿）

### 33.1 任务追踪

任务以日记条目形式记录，按时间排列可回顾。状态：未开始 / 进行中 / 完成 / 失败（过期）。不做地图任务标记。

### 33.2 任务类型（7 类）

| 类型 | 触发 | 奖励 |
|------|------|------|
| 生存任务 | 自动（没钱/没住处时） | 金钱、住处、基础道具 |
| 探索任务 | 到达新区/发现 POI | 成长点、区知识、好感度 |
| 社交任务 | NPC 好感度变化 | 技能传授、队友邀请、情报 |
| 传承任务 | 壮年后/老年 | 为下一代铺路（配方/物品/声望） |
| 异常任务 | 获得异常后 | 异常强化/抑制/转生线索 |
| 休闲任务 | 主动选择 | 低压力活动，小奖励，调节节奏 |
| 地牢任务 | 特定 POI 触发 | 副本型多层推进，大奖励 |

休闲任务示例：钓鱼（潮湾海岸）、逛公园（莲坪）、看展览（关山月美术馆）。

地牢任务示例：代班加班（科技园深夜副本，3 层：工位→会议室→老板办公室）、城中村探险（3 层：巷子→天台→地下室）。

### 33.3 事件池

| 事件分类 | 数量目标 |
|---------|---------|
| 区专属事件 | 每区 8-12 个（× 11 区 = 88-132） |
| 通用事件 | 40-50 个 |
| 阶段专属事件 | 每阶段 5-8 个（× 6 阶段 = 30-48） |
| 异常事件 | 20-25 个 |
| 连锁事件 | 10-15 条链 |
| 时代专属事件 | 每代 5-8 个（× 8 代 = 40-64） |
| 总计 | 约 250-350 个 |

### 33.4 连锁事件

- 完成后解锁后续事件，可在数年后/换区后/跨代触发
- 跨代连锁：上一代未完成的，下一代可继承线索继续
- 奖励通常是稀有装备/强力技能/大量共鸣碎片

### 33.5 鲲城发展时间线（8 代框架）

| 代数 | 时代 | 鲲城特征 | 独特内容 |
|------|------|---------|---------|
| 第 1 代 | 1980s | 经济特区刚成立，到处工地 | 建筑/工地事件、寻呼机、外来工文化 |
| 第 2 代 | 1990s | 制造业起飞 | 工厂/流水线、港客、城中村形成 |
| 第 3 代 | 2000s | 城市化加速 | 拆迁/补偿、科技园萌芽、二线关 |
| 第 4 代 | 2010s | 创业潮 | 创业/融资、共享经济、创客文化 |
| 第 5 代 | 2015s | 房价暴涨 | 扎根政策、房价焦虑、互联网+ |
| 第 6 代 | 2020s | 科技巨头 | AI/大数据、内卷、直播经济 |
| 第 7 代 | 2025s | 智慧城市 | 无人化、元宇宙、老龄化 |
| 第 8 代 | 2030s+ | 未来鲲城 | 取决于前 7 代积累 |

每代有独特事件池、敌人形态、可用收入来源、区域开发程度。部分区在早期代数未开发（边埔、禾塘在 1-2 代是荒地）。

### 33.6 Roguelike 事件生成

- 每次进入新区/新阶段，从事件池 roll 1-3 个候选
- 事件池按权重筛选：区专属 > 阶段专属 > 通用
- Roguelike 种子影响区法则偏移方向（同种子下特定区偏移固定）
- 法则偏移改变事件参数（偏"湿"的野坪淋雨概率 ×3，火焰异常 -50%）

## 三十四、生命周期系统（Layer 4 定稿）

### 34.1 人生阶段与控制权

| 年龄段 | 可控动作/年 | 控制模式 | 节奏 |
|--------|-----------|---------|------|
| 0-5 岁（婴儿/幼儿） | 0（自动） | 关键选择 + 突发事件 | 极快 |
| 6-12 岁（童年） | 4 | 二级菜单 + 无厘头选项 | 快 |
| 13-18 岁（少年） | 10 | 完整菜单 | 中 |
| 19-80 岁（青年/壮年/中年） | 14 | 完整菜单 | 慢 |
| 81+ 岁（老年） | 14 | 完整菜单（属性衰退） | 慢 |

**前期快后期慢**：婴儿期数秒过完，童年每年几个选择就走，成年后每年 14 个动作要慢慢经营。体感上越活越沉。

### 34.2 婴儿期（0-5 岁）

- **全自动播放**，但穿插两类交互：
  - **关键选择**：投胎签结果让你选鲲生/过江客（如果随机到了可选项）。这些选择影响一生走向。
  - **突发事件**：随机 1-3 个婴儿期事件，如"你学走路摔了"（躯干-1）、"你被亲戚夸好可爱"（机缘+1）、"你爸跑了"（金钱大幅减少）。
- 自动播放以快进叙事呈现，不占玩家时间，但结果会编入角色面板。

### 34.3 童年期（6-12 岁）—— 二级菜单 + 无厘头

每年 4 个可控动作，每个动作打开后是一个**二级菜单**，除了正经选项外还有无厘头选项：

**学习** → 写作业 / 偷看同桌答案 / 早恋（是的，6 岁也可以早恋）/ 逃课去小卖部
**玩** → 捉迷藏 / 玩鼻屎 / 试图驯服小区野猫 / 把邻居家的门铃按一遍就跑
**社交** → 交朋友 / 跟同学借零食不还 / 告老师 / 在班里搞小团体
**探索** → 去公园 / 去商场 / 偷偷坐公交坐到终点站 / 翻垃圾桶找"宝物"

- 无厘头选项不是纯搞笑——它们有真实的（通常是奇怪的）后果。玩鼻屎可能 +1 感知但 -3 好感。早恋 6 岁版会给家长一个"你确定？"的确认弹窗。
- 童年期选项的设计原则：**让玩家觉得"这小孩真烦"，但每个选择都有数值钩子。**

### 34.4 成年后（19+）—— 摸鱼机制

- 19+ 每年 14 个动作，玩家可以选择**"什么都不做"度过一个时段。
- **摸鱼代价**：
  - 无属性增长（本时段不触发成长检定）
  - 扣金钱（日常开销照扣）
  - **增加体重**（新状态：体重值）
  - **降低行动力**（下一时段行动力 -1，可累积）
  - 增加"躺平"心情标签（影响部分事件触发）
- 体重是持续状态属性，影响行动力上限、闪避率、部分事件判定。可以通过运动类动作（跑步/游泳/爬山）消耗。
- 摸鱼不是惩罚机制——它是一个"你选择活着但没在努力"的选项，有自己的叙事和后果。有时候你就是想躺一年。

### 34.5 婚姻与生育

- **19 岁起可结婚**，结婚不是必选项。
- 结婚条件：与某 NPC 好感度达到阈值 + 触发结婚事件 + 选择结婚。
- 生育条件：已婚 + 触发生育事件（或主动选择生育）。
- **不结婚/不生子**：这一世角色正常活到死，死后没有下一代继承——**一世游戏结束**，进入结局结算。
  - 这是一种合法的短 run 玩法：你只想过一生，不关心传承。游戏尊重这个选择，给出对应的短 run 结局。
- 不结婚不等于不能谈恋爱——恋爱是社交/事件的一部分，只是不进入婚姻系统就不生后代。

### 34.6 衰老与死亡

**死亡不是到点触发，是生命值掉落速度的变化。**

- 90 岁后 HP 自然流失速度加快（每时段 -X HP），正常情况下 90-100 岁左右死亡。
- 120 岁为强力道具延寿极限——能撑到这里的角色非常少。
- 150 岁为硬性强制老死，无论如何不超过。
- 三条死亡线不变（90 正常 / 120 道具 / 150 强制），但实现方式是**HP 流速曲线**而非即时判定。

**延寿道具类型**（现实产品的魔改版）：

| 道具名 | 效果 | 来源 |
|--------|------|------|
| 脑白金（真） | 降低 HP 流失速度 30%，持续 3 年 | 特殊活动/事件 |
| 生命一号（未过期） | 恢复 HP 至当前上限的 50%，一生限用 1 次 | 稀有商店/事件 |
| 太极晨练卡 | 每年额外恢复少量 HP，持续生效 | 老年大学任务奖励 |
| 基因检测报告 | 预知 HP 流失曲线，可提前规划 | 购买/任务 |
| 续命保险 | 死亡时保留 10% 属性给下一代 | 商城/特殊 NPC |

- 延寿道具的命名风格：**现实存在的东西 + 魔改效果 + 一个让你犹豫的代价或限制。**
- "脑白金（真）"暗示市面上卖的是假的，只有这个是真的。"生命一号（未过期）"暗示过期了会怎么样——谁知道呢。

### 34.7 体重系统（新增状态属性）

| 体重状态 | 行动力上限 | 闪避率 | 触发条件 |
|---------|-----------|--------|---------|
| 偏瘦 | -1 | +10% | 连续摸鱼不吃饭 / 过度运动 |
| 正常 | 标准 | 标准 | 默认 |
| 偏胖 | 标准 | -5% | 连续摸鱼 + 不运动 |
| 肥胖 | -2 | -15% | 长期摸鱼累积 |
| 魔改体型 | 特殊 | 特殊 | 持有特定异常/装备 |

- 体重通过运动类动作消耗、通过摸鱼和特定食物增加。
- 不是纯负面——某些异常/技能/事件在"肥胖"状态下有特殊效果（如"肉盾"技能在肥胖时减伤+20%）。
- 体重可以跨年龄变化，不是永久状态。

## 三十五、继承系统（Layer 4 定稿）

### 35.1 继承内容清单

| 类别 | 是否继承 | 说明 |
|------|---------|------|
| 技能配方 | ✅ | 每代固定减半学习难度，可多代叠加 |
| 装备 | ✅ | 有损耗——耐久度继承时打 7 折 |
| 部分道具 | ✅ | 关键道具独立存放，100% 继承；普通道具受背包上限限制 |
| 金钱 | ✅ | 扣除遗产税后继承 |
| 房产 | ✅（概率） | 不是 100% 继承，详见 35.5 |
| 声望 | ✅ | 家族声望跨代传递，影响 NPC 初始态度 |
| 区知识 | ✅ | 上一代探索过的区，下一代有"家传地图"基础认知 |
| 共鸣碎片 | ✅ | 100% 继承，是跨代最稳定的硬通货 |
| 角色属性 | ❌ | 每代重新生成 |
| 当前任务进度 | ❌ | 但传承任务的线索可跨代保留 |
| 角色身上的异常状态 | ❌ | 装备上的异常可继承，角色本体异常不继承 |
| 体重 | ❌ | 每代从正常体重开始 |
| NPC 好感度 | ❌ | 但 NPC 有跨代记忆（见 35.6） |

### 35.2 子女生成规则

**基因混合 + 突变机制：**

- 下一代 6 组件基础值 = 父母双方对应组件的均值 ± 随机波动（±10%）
- **基因突变概率**：每个组件有 15% 概率发生突变——
  - 突变方向 50/50：正向突变（+30%~+50%）或负向突变（-30%~-50%）
  - 突变是这个系统最刺激的部分：你可能生出一个天才，也可能生出一个废物。你不知道是哪个。
- 下一代**直接跳过 0-5 岁婴儿期**，从 6 岁童年期开始。
  - 婴儿期只对第一代起始角色生效（投胎签事件）。
  - 从第二代开始，0-5 岁以一段简短叙事跳过："你出生在鲲城。你的父母是上一代角色。你 6 岁了。"

### 35.3 投胎签的代际传递

**鲲生身份是世袭的——但有一个回乡咒。**

- 上一代是鲲生 → 下一代也是鲲生（默认继承）
- 上一代是过江客且**扎根成功**（打赢扎根天敌 / 达到城市亲和度门槛）→ 下一代变鲲生
- 上一代是过江客且未扎根 → 下一代仍是过江客

**回乡咒事件——"爸妈回了老家"：**

- 鲲生家庭有 **低概率**（约 5-8%）触发特殊事件：父母决定返回老家，你被带回老家生活。
- 事件效果：你的身份暂时变为"过江客"，从老家重新来到鲲城。
- **"这里就像一个魔咒，终将返回。"**——无论你是鲲生还是过江客，鲲城总会把你拉回来。你可能在老家待几年，但剧情会把你送回鲲城。
- 这个事件不是惩罚，是叙事钩子。它制造了一种命运感：你以为你是地头，但你被推出了去；你以为你离开了，但你又回来了。

### 35.4 技能配方继承

- 每个技能配方在下一代学习该技能时，**固定减半当前学习难度**。
- 可跨多代叠加：

| 经过代数 | 学习难度 |
|---------|---------|
| 原始 | 100% |
| 1 代配方 | 50% |
| 2 代配方 | 25% |
| 3 代配方 | 12.5% |
| 4 代+ | 6.25%（几乎等于直接送） |

- 配方不占用背包格，记录在"家传技能簿"中。
- 同一技能如果两代都没人学，配方不会消失，但也不会继续减半——它停在最后一次传承时的难度。

### 35.5 房产继承与随机事件

**房产不是 100% 继承。** 上一代拥有房产时，下一代面临继承判定：

| 判定结果 | 概率 | 效果 |
|---------|------|------|
| 正常继承 | 50% | 直接获得房产，可入住 |
| 拆迁补偿 | 15% | 失去房产，获得巨额补偿款（房价 ×1.5-3.0 倍） |
| 烂尾楼 | 10% | 继承了一个停工楼盘的"产权"，无法入住，但未来可能复工升值（也可能永远烂尾） |
| 房产纠纷 | 10% | 亲戚/前配偶争夺产权，进入法律战（限时事件，赢了拿回，输了失去） |
| 拖欠房贷 | 10% | 继承房产但附带未还贷款债务，需持续还贷否则被法拍 |
| 意外失火 | 5% | 房产损毁，获得保险理赔（如果上一代买了保险），否则人财两空 |

- 拆迁和烂尾楼是鲲城特色——每个鲲城人都知道这两个词的分量。
- 烂尾楼是一个长期彩蛋：它可能在你这一代一文不值，但到了第 8 代突然复工变成核心地段豪宅。也可能永远烂着。
- 金钱继承的遗产税：固定 10% 扣除。负债不继承——上一代的债务到此为止，下一代从 0 开始（但也没有金钱继承）。

### 35.6 NPC 跨代记忆

- NPC 不继承好感度，但有**跨代记忆**：
  - 上一代与某 NPC 深交过，下一代初次见面时 NPC 会说"你是 XX 的孩子吧？"
  - 初始态度根据上一代与该 NPC 的关系偏移（深交→友好，结仇→警惕）
  - 部分 NPC 会传授"你家老爷子/老太太托我照看你"的独家任务
- 跨代记忆不是好感度继承——它是一个叙事层，让世界感觉你走了但世界还在。

### 35.7 血脉断绝

- 角色死亡时没有后代 → **血脉断绝**。
- 不允许过继/收养来强行延续。
- 触发特殊结局：**"最后的鲲生"**
  - 这个结局不是失败——它是一个有尊严的句号。
  - 结算画面：家谱树到此为止，最后一片叶子是你。你的积累（金钱/声望/区知识/共鸣碎片）进入最终结算。
  - "你在鲲城活了一辈子。或者说，几辈子。现在没有了。鲲城还在。"

## 三十六、城市亲和系统（Layer 4 定稿）

### 36.1 亲和度结构

**两层并存：**

- **区亲和度**：11 个区各独立，0-100 分。影响区内交互（商店/NPC/任务/POI）。
- **鲲城总亲和度**：11 区亲和度的加权均值（权重相同，简单平均）。影响结局判定。

| 亲和度区间 | 状态 | 称呼 |
|-----------|------|------|
| 0-19 | 陌生人 | "你谁啊？" |
| 20-39 | 眼熟 | "好像见过你" |
| 40-59 | 常客 | "又来啦" |
| 60-79 | 自己人 | "这条街你比我还熟" |
| 80-100 | 地头蛇 | "你说的事就是这条街的事" |

### 36.2 亲和度获取

| 获取方式 | 亲和度增量 | 说明 |
|---------|-----------|------|
| 住满 1 年（被动） | +3/年 | 以当前居住区计算，需实际有住处 |
| 完成区任务 | +8-12 | 区专属任务，一次性 |
| 打败区天敌 | +15-20 | 天敌掉落装备/异常 + 大幅亲和度 |
| 参加区活动 | +2-3/次 | 可重复，如广场舞/社区义诊/商圈促销 |
| 和区 NPC 深交 | +5-8 | 好感度达到"挚友"级别时触发一次性奖励 |
| 区内消费/做生意 | +1/次 | 微量累积，每年上限 +5 |

**节奏参考**（以单一区为例）：
- 纯被动住 10 年 = 30（眼熟→常客边界）
- 住 10 年 + 做 3 个区任务 = ~60（自己人）
- 住 10 年 + 打天敌 + 深交 2 个 NPC + 日常消费 = ~80（地头蛇）

玩家不可能 11 个区都刷到 80+，必须选择深耕哪几个区。这正是"做客→成为地头"需要多代积累的原因。

### 36.3 亲和度流失

| 流失原因 | 流失量 | 说明 |
|---------|--------|------|
| 长期不住 | -2/年 | 搬离后每年衰减，住回来后恢复累积 |
| 重大负面事件 | -10~20 | 被驱逐/犯罪/在区内闹事 |
| 区天敌未挑战成功 | -5 | 挑战失败有惩罚，但可重试 |
| 跨代传承衰减 | -30%（向下取整） | 下一代继承区知识但亲和度打 7 折 |

- 流失不会降到 0 以下（0 = 陌生人，不能再差了）。
- 跨代 7 折意味着：如果这一代把某区刷到 100，下一代从 70 开始；再下一代从 49 开始。**单区不可能靠一代人永久锁死，需要持续经营。**

### 36.4 "地头"门槛

成为"地头"需同时满足：

1. **鲲城总亲和度 ≥ 70**
2. **至少 5 个区亲和度 ≥ 60**
3. **持有"扎根"状态**（鲲生自带；过江客需打赢扎根天敌"扎根窗口的玻璃后面"）

- 这三个条件保证了：你不能只宅在一个区（需要 5 个区），不能浮于表面（需要 70 总分），也不能只是暂住（需要扎根）。
- 跨代积累是达成这个门槛的核心手段——一代人很难把 5 个区都刷到 60+，但多代 7 折传承 + 持续深耕可以。

### 36.5 鲲生 vs 过江客起始差异

| 身份 | 出生区亲和度 | 其他区 | 亲和度获取倍率 | 扎根 |
|------|------------|--------|-------------|------|
| 鲲生 | **+20**（仅出生区） | 0 | ×1.2 | 自带 |
| 过江客 | 0 | 0 | ×1.1 | 需打赢天敌 |

- 鲲生只对**自己长大的那个区**有起始加成——你在云墩长大不代表你了解野坪。
- 过江客虽然从 0 开始，但获取倍率 +10% 作为补偿（他们更努力地融入）。
- 鲲生的 +20 起始 + ×1.2 倍率 = 在出生区有显著优势，但不影响其他区。要成为"地头"仍然需要走出舒适区。

### 36.6 亲和度的实际效果（暂定）

| 区亲和度 | 解锁内容 |
|---------|---------|
| ≥ 30 | 解锁区专属商店和常规区任务 |
| ≥ 50 | NPC 初始态度友好，物价 95 折 |
| ≥ 70 | 解锁区隐藏 POI、异常线索、区专属事件链 |
| ≥ 90 | 可学区专属强力技能（每个区 1 个） |

- 区专属技能示例（每个区一个，≥ 90 才能学）：
  - 金涌：中环节奏（战斗中每回合额外恢复 1 行动力）
  - 云墩：云端直觉（异常触发率 +15%）
  - 旧墟：墟市嘴炮（说服类行动成功率 +30%）
  - 铁围：围城毅力（受到致命伤害时保留 1HP，每场战斗一次）
  - 岔岗：岔路韧性（组件受伤后恢复速度 ×2）
  - 盐澳：盐澳交际（商店购买额外获得赠品道具）
  - 野坪：围坪阵（防御姿态减伤 +15%）
  - 禾塘：禾塘体质（体重状态永远为"正常"，免疫肥胖）
  - 钟岭：钟摆铁人（行动力消耗 -1/回合，最低 1）
  - 潮湾：潮音心境（异常自行爆发概率 -10%）
  - 边埔：拓埔者（未开发区也能正常探索，不受开发度限制）

## 三十七、Roguelike 与结局系统（Layer 4 定稿）

### 37.1 Roguelike 种子

- 种子在整个 run（8 代）期间**锁定不变**，保证世界连贯性。
- 种子影响：区法则偏移方向 + 敌人分布 + 事件池 roll 结果。
- 换 seed = 新 run。同一 seed 下世界规则一致，玩家可以尝试不同策略。
- 存档后种子锁定，不允许中途换 seed。

### 37.2 死亡与转场

**角色死亡 = 本世结束，不能读档。**

转场流程：
1. 角色死亡画面（死因不同画面不同：老死/战死/崩溃）
2. **家谱树画面**——更新家谱，已故角色灰显，新角色点亮
3. **选择：你要离开鲲城吗？**
   - **留下** → 正常继承流程（技能配方/装备/金钱/房产等按第三十五章规则传承），下一代从 6 岁开始
   - **离开** → 下一代回到鲲城（"这里像一个魔咒，终将返回"），但**没有任何继承，从零开始**——无金钱、无装备、无技能配方、无区知识、无声望。时间线变动（跳到下一个时代节点）。
     - 这是一个"核弹按钮"：当你这一世烂到不想继承任何东西时，可以选择一把火烧掉重来。
     - 离开不等于结束——你总会回来。只是回来时什么都没有。

4. 下一代角色生成（基因混合 + 突变，见 35.2）
5. 简短叙事过渡："你的父亲/母亲在鲲城活了 XX 年。现在轮到你了。"

### 37.3 结局类型（5 种）

| 结局 | 触发条件 | 性质 |
|------|---------|------|
| **鲲城为你而生** | 成为地头 + 额外条件（全 11 区 ≥80 / 或持有 5+ 红色异常 / 或打败 10+ 天敌） | 终极胜利 |
| **成为地头** | 满足亲和度门槛（总 ≥70 + 5 区 ≥60 + 扎根）+ 存活到自然死亡 | 标准胜利 |
| **最后的鲲生** | 角色死亡时无后代（血脉断绝） | 中性结局 |
| **离开鲲城** | 仅在第 8 代（最后一代）可选离开 | 放弃结局 |
| **被吞了** | 在致死战斗中死亡 / 稳定值归零（精神崩溃） | 失败结局 |

**结局说明：**

- **鲲城为你而生**：不只是留下来，而是鲲城认你。结算画面：你走过每一条街，每个人叫你的名字。你不是地头——你是这座城市的一部分。额外条件满足越多，结算画面越丰富。
- **成为地头**：你做到了你父母、你祖父母可能没做到的事。结算画面：户口本上写着你的名字。你终于不用再说"我刚来"。
- **最后的鲲生**：血脉到此为止。结算画面：家谱树最后一片叶子是你。你的积累进入总成绩。不是失败，是一个有尊严的句号。
- **离开鲲城**：只有第 8 代可以选。你用尽了 8 代人的时间，最终选择离开。结算画面：你站在鲲城北站，背对这座城市。它没有挽留你。但你回头看了一眼。
- **被吞了**：不是老死，是被吞噬。致死战斗失败 / 稳定值归零。结算画面：你还在鲲城。但你已经不是你了。

### 37.4 通关条件

- **8 代之内**达成"成为地头"或"鲲城为你而生" = **通关胜利**。
- 可以在任意一代达成——第 1 代就达成是理论可能的（但极难）。
- 8 代用完仍未达成 = **结算失败**，但保留成绩（家谱树、积累统计、解锁内容）。
- 每一代的角色死亡后进入下一代，直到第 8 代死亡或提前达成结局。

### 37.5 Meta 进度（跨 run 永久解锁）

每次完整 run（无论胜负）结束后，根据表现解锁永久内容：

| 解锁条件 | 永久解锁内容 |
|---------|------------|
| 通关 1 次 | 新出身类型（如"海归派"——起始有海外技能但亲和度全 0） |
| 打败 1 个天敌 | 该天敌的"记忆"——下一 run 遇到时显示弱点提示 |
| 打败 5 个天敌 | 解锁天敌图鉴，可查看所有天敌机制 |
| 达成"鲲城为你而生" | 解锁隐藏出身"鲲城之子"——起始全区亲和度 +10 |
| 达成"最后的鲲生" | 解锁特殊起始道具"家谱残页"——可查看上一 run 的家谱 |
| 累计游玩 3 个 run | 解lopen种子选择——可以手动输入种子号 |
| 单 run 击败 8+ 天敌 | 解lopen天敌猎手称号——起始多 1 个异常槽位 |

**天敌铸造系统**（核心 Meta 进度）：

- 在本 run 中击败的天敌，可以在结算时**铸造为最高级异常装备**。
- 每个天敌对应一件专属黑色（最高稀有度）异常装备，效果与天敌的机制相关：
  - "楼梯口的六年级" → 恐惧光环（战斗开始时敌方行动力 -2）
  - "查重率 99.8%" → 相似度检测（攻击时复制敌方上一个行动的效果）
  - "拿着纸箱的人" → 纸箱堡垒（防御姿态减伤 +50%，但每回合扣钱）
  - "扎根窗口的玻璃后面" → 积分屏障（每回合累积 1 层积分护盾，抵消等量伤害）
  - 以此类推，34 个天敌 = 34 件可铸造黑色异常装备
- 铸造的装备**可在下一 run 开始时选择 1 件携带**（携带数量随通关次数增加，最多 3 件）。
- 这是 Rogue-lite 的核心驱动力：**你打过的恐惧，变成你下一轮的武器。**

### 37.6 难度曲线

- **不主动加难**——每一代不因为代数增加而获得数值惩罚。
- 难度变化由**鲲城发展时间线**自然产生：
  - 后期代数有更狠的天敌（996/内卷/AI 替代），但也有更好的道具和收入来源。
  - 早期代数天敌简单但资源匮乏，后期代数资源丰富但天敌致命。
- 玩家的跨代积累 vs 世界的时代进化形成**动态平衡**——你变强了，鲲城也变了。
- "离开"机制（从零开始）是一个自动平衡阀：如果某一代继承的烂摊子太烂，玩家可以选择放弃继承重新来。
